ROS Topic

ROS Topic Node 將 ROS 2 Message 顯示於 RoboSim。每個 Node 保留 Topic Name 與 Message Type，並在 Inspector 提供對應的顯示設定。

Node 支援的 Message Type 顯示位置
TF tf2_msgs/msg/TFMessage Viewport
Pose geometry_msgs/msg/Pose、geometry_msgs/msg/PoseStamped Viewport
Image sensor_msgs/msg/Image Camera
Compressed Image sensor_msgs/msg/CompressedImage Camera
Marker visualization_msgs/msg/Marker Viewport
Marker Array visualization_msgs/msg/MarkerArray Viewport

Transform

TF

顯示 ROS Frame 的名稱、座標軸與父子關係箭頭。RoboSim 會合併 /tf 與 /tf_static 的資料，因此一個 TF Node 即可顯示目前的 Frame 結構。

Control

名稱 類型 預設值／選項 說明
Enabled Select true、false 啟用或停止 TF 顯示。
Show Names Select true、false 顯示或隱藏 Frame 名稱。
Show Axes Select true、false 顯示或隱藏 Frame 座標軸。
Show Arrows Select true、false 顯示或隱藏父子 Frame 之間的箭頭。
Scale Number 0.5 調整名稱、座標軸與箭頭的顯示尺寸。

Pose

Pose

以座標軸顯示位置與姿態。Pose 使用 World 座標；PoseStamped 會依 header.frame_id 轉換至 RoboSim World。

當 PoseStamped 的 Frame 無法由 TF 解析時，該筆 Pose 不會顯示。

Control

名稱 類型 預設值／選項 說明
Enabled Select true、false 啟用或停止接收 Pose。
Color Color 專案預設顏色 設定座標軸原點的顯示顏色與透明度。
Scale Number 0.5 調整 Pose 座標軸的顯示尺寸。

Image

Image

顯示未壓縮的 ROS Image。建立 Node 後，畫面會出現在對應的 Camera 頁面。

目前支援：

  • rgb8
  • bgr8
  • rgba8
  • bgra8
  • mono8

Control

名稱 類型 預設值／選項 說明
Enabled Select true、false 啟用或停止接收影像。
Fit Select Contain 保留完整畫面，空白區域不裁切。
Cover 填滿顯示區域，超出的部分會裁切。
Stretch 拉伸影像以填滿顯示區域。
Max FPS Number 15 限制畫面更新頻率。

Compressed Image

顯示壓縮的 ROS Image。建立 Node 後，畫面會出現在對應的 Camera 頁面。

目前支援 JPEG、JPG 與 PNG。

Control

名稱 類型 預設值／選項 說明
Enabled Select true、false 啟用或停止接收影像。
Fit Select Contain 保留完整畫面，空白區域不裁切。
Cover 填滿顯示區域，超出的部分會裁切。
Stretch 拉伸影像以填滿顯示區域。
Max FPS Number 15 限制畫面更新頻率。

Marker

Marker

顯示單一 ROS Marker。位置會依 header.frame_id 轉換至 RoboSim World；Frame 無法解析時不顯示該 Marker。

目前支援：

  • Arrow
  • Cube
  • Sphere
  • Cylinder
  • Line Strip
  • Line List
  • Points
  • Triangle List

Marker 的 Add、Modify、Delete 與 Delete All 操作均會更新 Viewport；具有 Lifetime 的 Marker 會在期限後移除。

Control

名稱 類型 預設值／選項 說明
Enabled Select true、false 啟用或停止接收 Marker。
Color Color Message 顏色 覆寫 Marker 顏色與透明度；未設定時保留 Message 提供的顏色。

Marker Array

依 Message 順序顯示多個 ROS Markers。每個 Marker 使用自己的 namespace、id、Frame、形狀、顏色與 Lifetime。

支援的形狀、操作與 Frame 規則和 Marker 相同。

Control

名稱 類型 預設值／選項 說明
Enabled Select true、false 啟用或停止接收 Marker Array。
Color Color Message 顏色 覆寫所有 Marker 的顏色與透明度；未設定時保留各 Marker 的顏色。
