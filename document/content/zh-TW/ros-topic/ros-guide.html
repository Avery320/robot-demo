ROS 操作指南

ROS Topic 是使用 WebSocker 技術與 ROS2 後端進行連線，將 ROS Topic 顯示。

連線設定

選擇 Bridge 與建立連線

專案提供 ROS Bridge 與 Foxglove Bridge 兩種連接方法，點選 Command/Ctrl + R 開啟 Robot 設定，切換不同的連線方式。

在 Ribbon 的 Robot 中，輸入 WebSocket URL，例如 ws://localhost:9090，進行連線，連線狀態會顯示於下方 log 中。

選項 說明
ROS Bridge 連接 rosbridge WebSocket。
Foxglove Bridge 連接 Foxglove Bridge WebSocket。

加入 ROS Topic

建立 Topic Node

  1. 先完成 ROS 連線。
  2. 在 Station Tree 選擇要放置 Topic Node 的 Frame；未選擇適合的位置時，Node 會建立於 World。
  3. 開啟 Tools > ROS Topic。
  4. 在 Topic Name 選擇 Topic。
  5. 確認自動顯示的 Message Type 與 Display Type。
  6. 點選 Add Topic。
欄位 說明
Topic Name 目前 Bridge 提供且 RoboSim 支援的 Topic。
Message Type Topic 的 ROS 2 Message Type，由系統自動讀取。
Display Type RoboSim 使用的顯示方式，由 Message Type 自動決定。

Topic 清單只顯示目前支援的 Message Type。若清單顯示 ROS is not connected，請先建立連線；若顯示 No supported topics found，代表目前 ROS Graph 沒有可加入的 Topic。

Topic Node 操作

Inspector

選擇 Station Tree 中的 ROS Topic Node，可在 Inspector 查看 Topic Name、Message Type 與 Display Type，並調整該顯示類型提供的設定。

Topic Name、Message Type 與 Display Type 由建立時的 Topic 決定，不在 Inspector 中修改。需要更換 Topic 時，請刪除原 Node，再加入新的 Topic。

Enabled 與 Visible

功能 說明
Enabled 啟用或停止該 Node 接收與處理 Topic 資料。
Visible 使用 Station Tree 的眼睛圖示顯示或隱藏 Viewport 內容，不會停止 Topic 訂閱。
Lock 鎖定後無法修改 Inspector 設定。

Image 與 Compressed Image 顯示於 Camera 頁面，不使用 Station Tree 的 Viewport Visible 狀態。

刪除 Node

刪除 ROS Topic Node 會停止該 Node 的 Topic 訂閱，並移除相關的 Viewport 或 Camera 顯示內容。

顯示方式

Viewport

下列 Topic 會顯示於 3D Viewport：

  • TF
  • Pose
  • Marker
  • Marker Array

PoseStamped、Marker 與 Marker Array 會使用 Message 的 frame_id 對齊 RoboSim 座標。若對應 Frame 尚未出現在 TF 中，該筆資料不會顯示。

Camera

Image 與 Compressed Image 會建立 Camera 頁面。Camera 頁面可留在 ROS Topic 面板，也可移動至 Viewport 內容區域。

TF Graph

連線後可使用 TF Graph 查看目前接收到的 Frame 關係。TF Graph 讀取系統的 TF 資料，不需要建立額外的影像或 Marker Node。

專案存取

RoboSim 專案會保存：

  • 選擇的 Bridge 與連線 URL。
  • Station Tree 中的 ROS Topic Nodes。
  • Enabled、顯示方式與各 Node 的調整值。

專案不保存 ROS Message 內容。重新開啟專案後，必須連接 ROS，Topic Node 才能重新接收即時資料。

常見問題

狀況 檢查方式
Topic 清單無法選擇 確認 ROS 已連線。
找不到預期 Topic 確認 Message Type 受 RoboSim 支援，並重新開啟 Topic 清單更新內容。
Pose 或 Marker 沒有顯示 確認 Message 的 frame_id 可由 TF 解析。
Image 沒有畫面 確認 Image encoding 或壓縮格式受支援，並檢查 Enabled。
Marker 部分內容沒有顯示 確認 Marker type、points 數量與 scale 符合該形狀需求。
