Node Editor 操作指南

Node Editor 用於建立資料、幾何與機器人控制流程。Node 之間以連線傳遞資料；具有幾何輸出的 Node 可直接在 Viewport 預覽，或 Bake 為專案幾何。

現有開發的 Node 分類

Node 會放置於 Canvas 左側，依 Group 的方式分類不同功能的 Node。

Group 說明
Parameter 建立數值、布林值與檢視資料。
Point 建立、量測與整理三維位置。
Plane 建立、調整與拆解 Plane。
Curve 建立與處理 Line、Polyline。
Mesh 取得 Viewport Mesh 與執行 Mesh 操作；功能文件待補。
OLP 建立機器人指令、預覽姿態、計算與播放。
Vector 建立與運算三維方向。
Math 執行數值運算與產生數值。
List 操作 List 與 Data Tree。

Node 基本操作

建立與搜尋

功能 操作方式 說明
搜尋與建立 在 Canvas 空白處按滑鼠左鍵兩下，或讓 Node Editor 取得焦點後按 Space。 輸入關鍵字後，搜尋結果會顯示完整的 Group / Sub Group / Node 路徑。
搜尋現有 Node 在既有 Node 上按住 Command + Option 並按滑鼠左鍵。 開啟該 Node 所屬的 Group，並定位其分類項目。

編輯 Node

操作 說明
Ctrl/Command + C 複製選取的 Node。
Ctrl/Command + X 剪下選取的 Node。
Ctrl/Command + V 貼上 Node。
Delete／Backspace 刪除選取的 Node、連線或 Group。
Ctrl/Command + Z 復原。
Ctrl/Command + Shift + Z 重做。
Ctrl/Command + Y 重做。

建立 Group

Group 用於將相關 Node 視為同一組操作，不參與資料運算。

操作 說明
Ctrl/Command + G 將選取的 Node 建立為 Group。
Ctrl/Command + Shift + G 取消選取 Node 所屬的 Group，或取消選取的 Group。

Node 連線操作

操作 說明
建立連線 從 Output 拖曳或點選至 Input，即可建立連線。也可由 Input 開始，再連接至 Output。<br>同一個 Input 預設只保留最新連線；建立新連線時，原有連線會自動移除。
多重連線 按住 Shift 建立第二條以上的連線，可將多個來源依連線建立順序傳入同一個 Input。資料順序以連線順序為準。<br>若順序會影響結果，應依預期順序逐一建立連線。
取消連線 按住 Ctrl 或 Command，再次連接相同的 Output 與 Input，可移除該條連線。<br>也可先選取連線，再按 Delete 或 Backspace。
自動增加輸入 Merge 會在成功連線後自動增加下一個 Input。移除尾端連線後，多餘的空白 Input 會自動移除，並保留一個可繼續連接的 Input。

Node 狀態與提示

狀態 顯示 說明
Normal 專案標準 Node 樣式 輸入資料有效，Node 已正常完成運算。
Warning 橘色 部分資料無法處理，但仍有有效輸出；或連線形成循環依賴。
Error 紅色 全部資料無法處理、無法產生有效輸出，或執行動作失敗。

Node 提示

將指標停留在 Node 標題或 Input／Output 上，可查看：

內容 說明
Node 名稱 顯示目前 Node 的名稱與主要用途。
Input 說明該輸入的資料。
Output 說明輸出的資料。

Node 對齊與排列

功能 操作方式 說明
Input／Output 自動對齊 拖曳 Node，讓 Input 或 Output 接近另一個 Node 的 Output 或 Input。 Node 會自動對齊兩者的高度，並顯示水平參考線。此功能不會將 Node 吸附至 Canvas 格點。
多個 Node 對齊 在 Canvas 空白處拖曳選取框，選取兩個以上的 Node。 選取範圍上方與右側會顯示排列工具，可進行靠左、水平置中、靠右、靠上、垂直置中與靠下對齊。
多個 Node 平均分布 使用選取框選取三個以上的 Node。 可依目前選取範圍進行水平或垂直平均分布。

Node 特有操作

Panel

Panel 可檢視資料，也可作為文字輸入。

  • 未連線時，可直接編輯多行文字並輸出 Text。
  • 連線後，顯示輸入資料的 Item、List 或 Data Tree 結構。
  • Panel 只格式化顯示內容，不會改變傳出的原始資料。
  • 內容超出 Panel 時可在內部捲動。
  • 可拖曳 Panel 邊界調整寬度與高度。

Number Slider

  • 拖曳 Slider 調整數值。
  • 在顯示數值上按滑鼠左鍵兩下，可輸入精確數值。
  • 在單一 Number Slider 上按滑鼠右鍵，可設定 Min、Max 與 Value。
  • 可水平拖曳 Node 邊界調整 Slider 寬度。

Action

具有 Action 的 Node 會顯示操作按鈕，例如 Run。

  • 點選按鈕後才執行對應功能。
  • 執行期間按鈕會暫時停用。
  • 執行失敗時，Node 會進入 Error 狀態並顯示錯誤提示。

Select

Select 用於選擇 Node 的控制選項，例如 Tool Frame 或 Configuration。選項由 Node 定義或目前專案狀態提供。

顯示操作

Node 顯示設定

在 Node 上按滑鼠右鍵可開啟操作選單。若已選取多個 Node，設定會套用至全部已選取 Node。

功能 說明
Preview 顯示或隱藏該 Node 的 Viewport 幾何預覽；只有具備幾何輸出的 Node 會顯示此項目。
Enable 啟用或停用 Node 執行。停用後不產生輸出。
Bake 將目前幾何結果建立為專案幾何；只有可預覽幾何的 Node 會顯示此項目。

Preview 只控制暫時顯示；Bake 建立的專案幾何不受 Preview 模式影響。

Viewport 預覽

  • 一般幾何預覽以紅色顯示。
  • 選取 Node 時，該 Node 的幾何預覽以綠色顯示。
  • 關閉 Node Editor 視窗不會自動清除 Node Graph 或 Viewport 預覽。

全域預覽模式

Canvas 右上角提供三種全域預覽模式：

功能 說明
Show all previews 顯示所有已開啟 Preview 的幾何 Node。
Show selected previews 只顯示目前選取 Node 的幾何結果。
Hide all previews 隱藏全部 Node 幾何預覽。

Node 自身的 Preview 關閉時，即使全域模式為 Show all previews，也不會顯示該 Node。

Canvas 操作

Zoom 操作

功能 說明
Zoom All 點選 Canvas 右上角的 Zoom All，將全部 Node 納入目前畫面。
Zoom Selected 選取 Node 或 Group 後，點選 Zoom Selected，將有效選取內容納入目前畫面。選取 Group 時，其成員 Node 會一併計算。
