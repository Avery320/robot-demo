Point

Point 用來表示三維空間中的位置。相關節點可建立、量測、拆解及整理位置資料；座標、距離與容差會依目前專案的長度單位輸入與顯示。

Create

Point XYZ

使用 X、Y、Z 座標建立 Point。

Input

名稱 型別 預設值／選項 說明
X Number 0 X 軸座標。
Y Number 0 Y 軸座標。
Z Number 0 Z 軸座標。

Output

名稱 型別 預設值／選項 說明
Point Point — 建立的三維位置。

Normal From Three Points

使用三個點計算法向量。點的輸入順序決定方向；輸入點重合或三點共線時無法計算。

Input

名稱 型別 預設值／選項 說明
Point 1 Point (0, 0, 0) 第一個參考點。
Point 2 Point (0, 0, 0) 第二個參考點。
Point 3 Point (0, 0, 0) 第三個參考點。
Reverse Normal Boolean false 啟用後反轉法向量。

Output

名稱 型別 預設值／選項 說明
Normal Vector — 垂直於三點所在平面的單位向量。

Measure

Point Distance

量測 Start Point 與 End Point 之間的直線距離。

Input

名稱 型別 預設值／選項 說明
Start Point Point (0, 0, 0) 距離量測的起點。
End Point Point (0, 0, 0) 距離量測的終點。

Output

名稱 型別 預設值／選項 說明
Distance Number — 兩點之間的距離。

Extract

Deconstruct Point

取得輸入位置的 X、Y、Z 座標。

Input

名稱 型別 預設值／選項 說明
Point Point (0, 0, 0) 要拆解的位置。

Output

名稱 型別 預設值／選項 說明
X Number — X 軸座標。
Y Number — Y 軸座標。
Z Number — Z 軸座標。

Average Point

計算 Point List 中所有位置的平均值。輸入 List 不可為空。

Input

名稱 型別 預設值／選項 說明
Points Point List — 要計算平均位置的 Point List。

Output

名稱 型別 預設值／選項 說明
Point Point — 所有輸入位置的平均值。

Closest Point

在 Point List 中尋找最接近指定位置的項目。若多個項目的距離相同，輸出排列最前的項目。

Input

名稱 型別 預設值／選項 說明
Points Point List — 用於搜尋的非空 Point List。
Point Point (0, 0, 0) 搜尋的參考位置。

Output

名稱 型別 預設值／選項 說明
Point Point — 距離參考位置最近的項目。

Closest Point Distance

量測指定位置與 Point List 中最近項目的距離。輸入 List 不可為空。

Input

名稱 型別 預設值／選項 說明
Points Point List — 用於搜尋的非空 Point List。
Point Point (0, 0, 0) 搜尋的參考位置。

Output

名稱 型別 預設值／選項 說明
Distance Number — 參考位置與最近項目的距離。

Closest Point Index

取得 Point List 中最近項目的 Index。Index 從 0 開始；若多個項目的距離相同，輸出排列最前的 Index。

Input

名稱 型別 預設值／選項 說明
Points Point List — 用於搜尋的非空 Point List。
Point Point (0, 0, 0) 搜尋的參考位置。

Output

名稱 型別 預設值／選項 說明
Index Number — 最近項目在輸入 List 中的位置。

Clean

Remove Consecutive Point Duplicates

依 Tolerance 移除相鄰的重複點，非相鄰的重複項目會保留。

Input

名稱 型別 預設值／選項 說明
Points Point List — 要整理的 Point List。
Tolerance Number 0.0000001 判斷重複位置的容差，必須大於或等於 0。
Check First And Last Boolean false 啟用後同時比較第一個與最後一個項目；重複時移除最後一個。

Output

名稱 型別 預設值／選項 說明
Points Point List — 移除相鄰重複項目後的 List。
