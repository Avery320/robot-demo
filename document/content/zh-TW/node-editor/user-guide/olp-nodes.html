OLP

OLP 節點將 Plane 或 Joint Target 組成機器人指令，再由 RoboSim 計算、預覽或播放。Plane 提供目標位置與姿態；Joint Target 提供六軸關節值；Program Settings 設定計算使用的起點與終點。

Create

Joint

由六個關節值建立 Joint Target。本節點只建立關節資料，不包含 Speed、Zone 或運動方式。

Input

名稱 型別 預設值／選項 說明
Joint 1 Number 0 第一軸關節值，單位為 degree。
Joint 2 Number 0 第二軸關節值，單位為 degree。
Joint 3 Number 0 第三軸關節值，單位為 degree。
Joint 4 Number 0 第四軸關節值，單位為 degree。
Joint 5 Number 0 第五軸關節值，單位為 degree。
Joint 6 Number 0 第六軸關節值，單位為 degree。

Output

名稱 型別 預設值／選項 說明
Joint Target OLP Joint Target — 包含六軸關節值的目標資料。

Start / End Settings

設定 OLP 計算的起始與結束姿態。

Input

名稱 型別 預設值／選項 說明
Start Joint OLP Joint Target — 程式開始時的關節姿態。
End Joint OLP Joint Target — 程式結束時的關節姿態。

Output

名稱 型別 預設值／選項 說明
Program Settings OLP Program Settings — 包含 Start Joint 與 End Joint 的計算設定。

MoveJ

由 Plane 建立關節插補指令。機器人以關節空間移動至目標，TCP 路徑不保證為直線。

Input

名稱 型別 預設值／選項 說明
Plane Plane — 機器人目標位置與姿態。
Speed Number 100 TCP 平移速度，單位為 mm/s，必須大於或等於 0。
Rotation Speed Number π TCP 旋轉速度，單位為 rad/s，必須大於或等於 0。
Zone Number 50 路徑轉接距離，單位為 mm；0 表示精準停點。

Output

名稱 型別 預設值／選項 說明
Instruction OLP Instruction — MoveJ 指令。

Control

名稱 類型 選項 說明
Tool Frame Select Ribbon 的 Tool Frame 清單 指定 Plane 所代表的 TCP。新節點預設使用目前啟用的 Tool Frame。
Configuration Select Auto 由 OLP 求解器自動選擇關節組態。
None 不指定 Shoulder、Elbow 或 Wrist 組態。
Shoulder 指定 Shoulder 組態。
Elbow 指定 Elbow 組態。
Wrist 指定 Wrist 組態。
Shoulder + Elbow 同時指定 Shoulder 與 Elbow 組態。
Shoulder + Wrist 同時指定 Shoulder 與 Wrist 組態。
Elbow + Wrist 同時指定 Elbow 與 Wrist 組態。
Shoulder + Elbow + Wrist 同時指定 Shoulder、Elbow 與 Wrist 組態。

MoveL

由 Plane 建立線性插補指令。OLP 會沿 Cartesian 路徑取樣並求解各取樣點的關節姿態。

Input

名稱 型別 預設值／選項 說明
Plane Plane — 機器人目標位置與姿態。
Speed Number 100 TCP 平移速度，單位為 mm/s，必須大於或等於 0。
Rotation Speed Number π TCP 旋轉速度，單位為 rad/s，必須大於或等於 0。
Zone Number 50 路徑轉接距離，單位為 mm；0 表示精準停點。
Segments Number 0 固定取樣段數。大於 0 時使用固定段數；0 表示依 Step Size 計算。
Step Size Number 0.01 Segments 為 0 時使用的取樣間距，依專案長度顯示單位輸入。

Output

名稱 型別 預設值／選項 說明
Instruction OLP Instruction — MoveL 指令。

Control

名稱 類型 選項 說明
Tool Frame Select Ribbon 的 Tool Frame 清單 指定 Plane 所代表的 TCP。新節點預設使用目前啟用的 Tool Frame。

Input

名稱 型別 預設值／選項 說明
Joint 1 Number 0 第一軸目標角度，單位為 degree。
Joint 2 Number 0 第二軸目標角度，單位為 degree。
Joint 3 Number 0 第三軸目標角度，單位為 degree。
Joint 4 Number 0 第四軸目標角度，單位為 degree。
Joint 5 Number 0 第五軸目標角度，單位為 degree。
Joint 6 Number 0 第六軸目標角度，單位為 degree。
Speed Number 100 平移速度設定，單位為 mm/s，必須大於或等於 0。
Rotation Speed Number π 旋轉速度設定，單位為 rad/s，必須大於或等於 0。
Zone Number 50 路徑轉接距離，單位為 mm；0 表示精準停點。

Output

名稱 型別 預設值／選項 說明

DO

建立設定 Digital Output 的指令。

Input

名稱 型別 預設值／選項 說明
Channel Number 1 Digital Output channel，必須為大於或等於 1 的整數。
Value Boolean true 設定該 channel 的輸出狀態。

Output

名稱 型別 預設值／選項 說明
Instruction OLP Instruction — Digital Output 指令。

Execute

Calculate

依輸入順序將一個以上的 OLP Instructions 組成程式，並使用目前的 Station、Robot 與 Program Settings 進行計算。Calculate 不會自動執行，必須按下 Run。

Input

名稱 型別 預設值／選項 說明
Instructions OLP Instruction List — 依序執行的指令。必須位於單一 List，且至少包含一個 Instruction。
Program Settings OLP Program Settings Start／End Joint 1–6 均為 0 設定程式開始與結束的關節姿態；未連線時使用固定零值。

Output

名稱 型別 預設值／選項 說明
Result OLP Result — 計算完成後提供給 Playback 使用的結果。

Control

名稱 類型 選項 說明
Run Action — 使用目前的 Instructions 與 Program Settings 執行 OLP 計算。

Robot Preview

將單一運動指令直接套用至 Viewport Robot，用於快速查看 MoveJ、MoveL 或 MoveAbsJ 的目標姿態。此節點不執行完整 OLP 計算，也不產生 Result。

  • MoveJ／MoveL：使用指令中的 Plane 與 Tool Frame，透過 Viewport 的 TCP 控制與 IK 求解更新 Robot。
  • MoveAbsJ：將六軸關節值直接套用至 Viewport Robot。

Input

名稱 型別 預設值／選項 說明
Instruction OLP Instruction — 一個 MoveJ、MoveL 或 MoveAbsJ 指令。

Control

名稱 類型 選項 說明
Run Action — 立即更新 Viewport Robot 與 Joint 顯示。Program Playback 執行中或目標無法套用時會顯示錯誤。

Playback

播放 Calculate 產生的 OLP Result。Result 必須仍存在於目前執行階段；重新計算後應使用新的 Result。

Input

名稱 型別 預設值／選項 說明
Result OLP Result — Calculate 已完成的計算結果。

Control

名稱 類型 選項 說明
Run / Pause Action — 載入 Result，並切換播放或暫停。
Speed Select 0.5x、1x、2x、5x、20x、50x、100x、200x 設定播放速度，預設為 5x。
Timeline Slider 0 至 Result 總時間 調整播放時間；操作時會暫停播放，間隔為 0.01。
