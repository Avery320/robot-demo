Math

Math 節點用於建立數值與比較運算流程。Number Input 可以直接在節點中輸入數值，或連接其他節點的 Number、List 或 Data Tree；連接 List／Data Tree 時，系統會依既有 Branch 結構逐項運算。

若輸入超出運算定義，例如除以 0、對負數開平方根，或產生無限值，節點會顯示資料錯誤且不輸出無效 Number。

Operations

Two Numbers

用於兩個數值之間的基本算術。將主要數值連接至 First、另一個運算值連接至 Second，再由 Operation 選擇計算方式。

First 與 Second 的順序會影響 Subtract、Divide、Power 與 Modulus。例如 First 為 10、Second 為 3 時，Subtract 的結果是 7，Modulus 的結果是 1。

Input

名稱 型別 預設值／選項 說明
First Number 1 主要運算值。
Second Number 1 第二個運算值。

Output

名稱 型別 預設值／選項 說明
Result Number — 依 Operation 計算出的數值。

Control

名稱 類型 選項 說明
Operation Select Add 將 First 與 Second 相加，適合計算總和或增加偏移量。預設選項。
Subtract 從 First 減去 Second，適合計算兩個數值的差。
Multiply 將 First 與 Second 相乘，適合套用倍率或比例。
Divide 將 First 除以 Second，適合計算比例；Second 不可為 0。
Power 以 First 為底數、Second 為指數進行次方運算。
Modulus 取得 First 除以 Second 的餘數，適合循環索引或週期判斷；Second 不可為 0。

Compare

依 Operator 比較 A 與 B，並輸出比較結果。數值大小比較通常使用 <、<=、> 或 >=；需要確認兩個值是否相同時，應優先使用 === 或 !==。

A 與 B 是通用 Value，但不同 Operator 適用的資料不同。大小比較適合 Number 或 Text；Geometry Artifact 等 Object 不會比較幾何內容，嚴格相等只會判斷兩者是否為同一份物件資料。

Input

名稱 型別 預設值／選項 說明
A Value no-data 比較式左側的資料。
B Value no-data 比較式右側的資料。

Output

名稱 型別 預設值／選項 說明
Boolean Boolean — A 與 B 是否符合 Operator 的比較結果。

Control

名稱 類型 選項 說明
Operator Select < A 小於 B 時輸出 true。預設選項。
<= A 小於或等於 B 時輸出 true。
> A 大於 B 時輸出 true。
>= A 大於或等於 B 時輸出 true。
=== Primitive 的型別與值皆相同時輸出 true；Object 只比較是否為同一份資料。
!== A 與 B 不符合嚴格相等時輸出 true。
== 比較前允許 JavaScript 進行型別轉換，例如 Number 1 與 Text 1 會視為相同。
!= 比較前允許型別轉換，轉換後不同時輸出 true。

Round To Decimals

將輸入數值四捨五入到指定的小數位。將原始數值連接至 Number，並以 Decimal Places 設定要保留的位數。

例如 Number 為 1.32156、Decimal Places 為 3 時，Result 為 1.322。輸出仍是 Number，不會保留沒有數值意義的結尾 0；若需要固定格式的文字，請使用 To Fixed。

Input

名稱 型別 預設值／選項 說明
Number Number 1.123456 要進行四捨五入的數值。
Decimal Places Number 2 要保留的小數位數。

Output

名稱 型別 預設值／選項 說明
Result Number — 四捨五入後可繼續參與數值運算的結果。

One Number

用於只需要一個輸入值的數學運算。將數值連接至 Number，再由 Operation 選擇絕對值、對數、取整數、三角函數或角度轉換。

三角函數 Sin、Cos、Tan 使用弧度；若輸入是角度，應先選擇 Degrees to Radians 轉換。部分運算有輸入範圍限制，超出範圍時不會輸出無效結果。

Number Number 1 要套用 Operation 的數值。

Square Root 計算平方根；Number 必須大於或等於 0。

Remap

將數值由一個區間等比例轉換到另一個區間。先以 Source Low／Source High 定義原始區間，再以 Target Low／Target High 定義輸出區間。

例如將 0–100 轉換為 0–1 時，Number 為 50 會得到 0.5。Number 可位於來源區間之外，此時 Result 也會依相同比例延伸至目標區間之外；Source Low 與 Source High 不可相同。

Input

名稱 型別 預設值／選項 說明
Number Number 0.5 要轉換的原始數值。
Source Low Number 0 原始區間的起點。
Source High Number 1 原始區間的終點，不可與 Source Low 相同。
Target Low Number 1 目標區間的起點。
Target High Number 2 目標區間的終點。

Output

名稱 型別 預設值／選項 說明
Result Number — Number 在目標區間中的等比例對應值。

Ease

將 0–1 之間的 X 轉換成具有加速、減速或彈性變化的數值，再映射到 Min 與 Max。適合控制動畫進度、漸變參數或不希望線性變化的運動數值。

X 為 0 時位於變化起點，X 為 1 時位於終點。Ease In 主要調整起步方式，Ease Out 主要調整到達終點的方式，Ease In Out 同時調整兩端。Elastic 與 Back 曲線可能暫時超出 Min／Max，適合需要振盪或超越效果的流程。

Input

名稱 型別 預設值／選項 說明
X Number 0.5；範圍 0 至 1 曲線上的進度位置，0 代表起點、1 代表終點。
Min Number 0 輸出範圍的起點。
Max Number 1 輸出範圍的終點。

Output

名稱 型別 預設值／選項 說明
Result Number — 依選定曲線計算並映射至 Min／Max 的數值。

Control

easeInOutSine 正弦緩入／緩出，起點與終點均平滑。

easeOutQuad 二次方緩出，快速起步後持續減速。

easeOutCubic 三次方緩出，比 Quad 具有更明顯的減速。

easeInOutBounce 反彈緩入／緩出，在起點與終點區段都產生反彈。

Clamp

將 Number 限制在 Min 與 Max 之間。數值低於 Min 時輸出 Min，高於 Max 時輸出 Max，位於範圍內時保持原值。

此節點適合限制百分比、速度、尺寸或其他不可超出指定上下限的參數。例如 Min 為 0、Max 為 10 時，輸入 15 會得到 10。使用時應讓 Min 小於或等於 Max。

Input

名稱 型別 預設值／選項 說明
Number Number 0.5 要檢查並限制的數值。
Min Number 0 允許輸出的最小值。
Max Number 1 允許輸出的最大值。

Output

名稱 型別 預設值／選項 說明
Result Number — 限制在 Min 與 Max 之間的數值。

Lerp

依 T 計算 Start 到 End 之間的線性位置。T 為 0 時輸出 Start，T 為 1 時輸出 End，T 為 0.5 時輸出兩者中間值。

T 不會自動限制於 0–1。小於 0 或大於 1 時，Result 會沿相同方向延伸到 Start／End 範圍之外。

Input

名稱 型別 預設值／選項 說明
Start Number 0 線性變化的起始值。
End Number 1 線性變化的終點值。
T Number 0.5 Start 到 End 的位置比例。

Output

名稱 型別 預設值／選項 說明
Result Number — 依 T 計算出的線性插值或延伸值。

Sign

判斷 Number 的方向，不保留原始大小。負數輸出 -1、零輸出 0、正數輸出 1。

此結果適合用於判斷移動方向、建立正負方向倍率，或配合 Compare 與 Value Gate 控制資料流程。

Input

名稱 型別 預設值／選項 說明
Number Number 0 要判斷正負方向的數值。

Output

名稱 型別 預設值／選項 說明
Result Number — Number 的符號值：-1、0 或 1。

To Fixed

將 Number 轉換為具有固定小數位數的 Text。與 Round To Decimals 不同，此節點會保留結尾的 0，適合顯示、標籤或輸出固定格式文字。

例如 Number 為 5、Decimal Places 為 3 時，Text 為 5.000。輸出型別是 Text，不能直接當作 Number 繼續進行數值運算。

Input

名稱 型別 預設值／選項 說明
Number Number 1 要轉換為固定格式文字的數值。
Decimal Places Number 2 文字中固定顯示的小數位數；應使用 0 至 100 的整數。

Output

名稱 型別 預設值／選項 說明
Text Text — 保留指定小數位與結尾 0 的文字。

Generate

Random Numbers

依指定範圍與數量建立一組可重現的偽隨機數值。先以 Low／High 設定範圍、Count 設定數量，再以 Seed 決定序列。

相同的 Low、High、Count 與 Seed 會產生相同結果，因此 Canvas 重新運算時不會任意改變數值。需要另一組序列時，只要更改 Seed；兩個設定完全相同的 Random Numbers 節點也會輸出相同序列。

Input

名稱 型別 預設值／選項 說明
Low Number 0 每個隨機數值的範圍起點。
High Number 1 每個隨機數值的範圍終點。
Count Number 10 要產生的數值數量，必須為非負整數。
Seed Number 1 決定序列內容的整數；更改 Seed 可取得另一組結果。

Output

名稱 型別 預設值／選項 說明
Numbers Number List — 依範圍、數量與 Seed 產生的數值序列。

Pi

將輸入的 Number 乘以圓周率 π。Number 可作為 π 的倍率：輸入 1 得到 π，輸入 2 得到 2π。

此節點可用於建立以 π 表示的角度或圓形計算；例如要取得半圈的弧度值，可輸入 1，要取得完整一圈則輸入 2。

Input

名稱 型別 預設值／選項 說明
Number Number 1 π 的倍率。

Output

名稱 型別 預設值／選項 說明
Result Number — Number 與 π 的乘積。
