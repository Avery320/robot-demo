List

List 節點用於建立、選取與調整有順序的資料。Tree 類別操作完整 Data Tree；其他類別會分別處理每個 Branch 內的 List。Index 從 0 開始。

Tree

Merge

依 Input 由上而下的順序合併 Data Tree。相同 Path 的 Items 會依序接續，不同 Path 會保留原有層級。

Input

名稱 型別 預設值／選項 說明
Tree 0…N Data Tree 至少兩個 Inputs 連線後自動增加下一個 Input；取消連線後移除多餘的 Input。

Output

名稱 型別 預設值／選項 說明
Tree Data Tree — 合併完成的 Data Tree。

Flatten

依 Branch Path 順序收集全部 Items，並放入單一根 Branch {0}。

Input

名稱 型別 預設值／選項 說明
Tree Data Tree — 要展平的 Data Tree。

Output

名稱 型別 預設值／選項 說明
Tree Data Tree — 所有 Items 位於 {0} 的 Data Tree。

Graft

將每個 Item 放入自己的子 Branch。新的 Path 會在原 Path 後加入該 Item 的 Index；空 Branch 會保留。

Input

名稱 型別 預設值／選項 說明
Tree Data Tree — 要增加層級的 Data Tree。

Output

名稱 型別 預設值／選項 說明
Tree Data Tree — 每個 Item 各自位於子 Branch 的 Data Tree。

Branch

依 Path 取得指定 Branch 的 Items。找不到 Path 時輸出空 List。

Input

名稱 型別 預設值／選項 說明
Tree Data Tree — 要查詢的 Data Tree。
Path Text {0} Branch Path，例如 {0;1}；每一層必須是非負整數。

Output

名稱 型別 預設值／選項 說明
List List — 指定 Branch 中的 Items。

Get

List Item

依 Index 取得一個 Item。Index 超出 List 範圍時產生錯誤。

Input

名稱 型別 預設值／選項 說明
List List — 要查詢的 List。
Index Number 0 Item 位置，必須為非負整數。

Output

名稱 型別 預設值／選項 說明
Item Value — 指定位置的原始資料。

Sub List

取得 Start 至 End 之間的 Items，結果包含 Start、但不包含 End。

Input

名稱 型別 預設值／選項 說明
List List — 要擷取的 List。
Start Number 0 起始 Index，必須為非負整數。
End Number 1 結束 Index，必須為非負整數且不包含在結果中。

Output

名稱 型別 預設值／選項 說明
List List — 指定範圍內的 Items。

By Pattern

依 Boolean Pattern 篩選 Items。Pattern 短於 List 時會循環使用；Pattern 為空或包含非 Boolean 資料時產生錯誤。

Input

名稱 型別 預設值／選項 說明
List List — 要篩選的 List。
Pattern Boolean List — true 保留對應 Item，false 排除對應 Item。

Output

名稱 型別 預設值／選項 說明
List List — Pattern 篩選後的 List。

List Length

取得 List 的 Item 數量。

Input

名稱 型別 預設值／選項 說明
List List — 要計算的 List。

Output

名稱 型別 預設值／選項 說明
Length Number — List 中的 Item 數量。

Edit

Reverse

反轉 List 的 Item 順序。

Input

名稱 型別 預設值／選項 說明
List List — 要反轉的 List。

Output

名稱 型別 預設值／選項 說明
List List — 順序反轉後的 List。

Shuffle

隨機重排 List 的 Item 順序。此節點沒有 Seed，每次重新運算可能得到不同結果。

Input

名稱 型別 預設值／選項 說明
List List — 要重新排列的 List。

Output

名稱 型別 預設值／選項 說明
List List — 隨機排列後的 List。

Add

Insert Items

將 Items 插入指定 Indexes。Index 等於 List 長度時會加在末端；超出範圍的 Index 不會插入資料。

Input

名稱 型別 預設值／選項 說明
List List — 原始 List。
Items List — 要插入的 Items。
Indexes Number List — 插入位置，必須為非負整數。

Output

名稱 型別 預設值／選項 說明
List List — 插入完成的 List。

配對方式：

  • 一個 Item 與多個 Indexes：將同一個 Item 插入每個位置。
  • 多個 Items 與一個 Index：由該位置依序插入全部 Items。
  • Items 與 Indexes 數量相同：依序一對一插入，Indexes 必須由小到大排列。
  • 其他數量組合會產生錯誤。

Remove

Remove Items

依 Indexes 移除 Items。超出 List 範圍的 Index 會被忽略。

Input

名稱 型別 預設值／選項 說明
List List — 原始 List。
Indexes Number List — 要移除的位置，必須為非負整數。

Output

名稱 型別 預設值／選項 說明
List List — 移除指定 Items 後的 List。

Remove Duplicates

使用嚴格相等比較移除重複 Items，並保留第一次出現的資料。Object 只有在參考相同時才視為重複。

Input

名稱 型別 預設值／選項 說明
List List — 要去除重複資料的 List。

Output

名稱 型別 預設值／選項 說明
List List — 保留第一次出現 Item 的 List。

Sorting

Sort Numbers

依數值大小排列 Number List。List 中包含非有限 Number 時會產生錯誤。

Input

名稱 型別 預設值／選項 說明
List Number List — 要排序的有限 Number List。
Ascending Boolean true true 為升冪，false 為降冪。

Output

名稱 型別 預設值／選項 說明
List Number List — 排序後的 Number List。

Sort Texts

依 JavaScript 字串順序排列 Text List。List 中包含非 Text 資料時會產生錯誤。

Input

名稱 型別 預設值／選項 說明
List Text List — 要排序的 Text List。
Ascending Boolean true true 為升冪，false 為降冪。

Output

名稱 型別 預設值／選項 說明
List Text List — 排序後的 Text List。
