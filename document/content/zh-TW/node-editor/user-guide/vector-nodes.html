Vector

Vector 節點用於建立與處理三維方向資料。Vector 由 X、Y、Z 三個分量組成，可表示方向、倍率或位移，但本身不代表空間中的固定位置；需要表示位置時應使用 Point。

每個 Input 可接收單一資料、List 或 Data Tree。連接 List／Data Tree 時，系統會保留既有 Branch 結構並逐項運算。需要使用 Vector 表示固定距離方向時，應先使用 Normalize 將 Vector 轉為長度 1 的單位向量。

Create

Vector XYZ

由 X、Y、Z 三個分量建立 Vector。可直接在三個 Input 中輸入數值，或連接其他 Math 節點建立可變方向。

Input

名稱 型別 預設值／選項 說明
X Number 0 Vector 的 X 分量。
Y Number 0 Vector 的 Y 分量。
Z Number 0 Vector 的 Z 分量。

Output

名稱 型別 預設值／選項 說明
Vector Vector — 由 X、Y、Z 組成的三維 Vector。

Sum

Add Vectors

將 A 與 B 的對應分量相加。適合合併多個方向或將位移增量加入既有 Vector。

Input

名稱 型別 預設值／選項 說明
A Vector [0, 0, 0] 第一個 Vector。
B Vector [0, 0, 0] 要加入 A 的 Vector。

Output

名稱 型別 預設值／選項 說明
Vector Vector — A 與 B 逐分量相加後的 Vector。

Base

Cross Product

計算 A 與 B 的叉積，取得同時垂直於兩個輸入方向的 Vector。輸出方向遵循右手定則，因此交換 A 與 B 會反轉結果方向。

Input

名稱 型別 預設值／選項 說明
A Vector [0, 0, 0] 叉積的第一個方向。
B Vector [0, 0, 0] 叉積的第二個方向。

Output

名稱 型別 預設值／選項 說明
Vector Vector — 依右手定則計算出的垂直 Vector。

Dot Product

計算 A 與 B 的內積並輸出 Number。內積可用於判斷兩個 Vector 的方向關係：結果為正表示方向較接近，為負表示方向相反，為 0 表示兩者垂直。

Vector 的長度會影響輸出大小。若只需要比較方向，應先將 A 與 B Normalize。

Input

名稱 型別 預設值／選項 說明
A Vector [0, 0, 0] 內積的第一個 Vector。
B Vector [0, 0, 0] 內積的第二個 Vector。

Output

名稱 型別 預設值／選項 說明
Number Number — A 與 B 各分量乘積的總和。

Subtract Vectors

從 A 逐分量減去 B。此運算可用於取得兩個方向的差，或由兩個位置資料建立方向差值。

Input

名稱 型別 預設值／選項 說明
A Vector [0, 0, 0] 被減的 Vector。
B Vector [0, 0, 0] 從 A 減去的 Vector。

Output

名稱 型別 預設值／選項 說明
Vector Vector — A 減去 B 後的 Vector。

Multiply Vector

將 Vector 的每個分量乘以 Scalar。適合保持原始方向並調整長度，或依比例放大與縮小位移量。

Scalar 大於 1 時增加 Vector 長度，介於 0 與 1 時縮短，等於 0 時得到零向量；負值會同時反轉方向。

Input

名稱 型別 預設值／選項 說明
Vector Vector [0, 0, 0] 要調整倍率的 Vector。
Scalar Number 1 套用至每個分量的倍率。

Output

名稱 型別 預設值／選項 說明
Vector Vector — 每個分量乘以 Scalar 後的 Vector。

Negate Vector

反轉 Vector 的方向，同時保留原始長度。此節點會將每個分量的正負號反轉。

Input

名稱 型別 預設值／選項 說明
Vector Vector [0, 0, 0] 要反轉方向的 Vector。

Output

名稱 型別 預設值／選項 說明
Vector Vector — 方向反轉、長度不變的 Vector。

Normalize

將 Vector 轉換為長度 1 的單位向量，同時保留原始方向。適合在只需要方向、不希望原始長度影響後續運算時使用。

Input

名稱 型別 預設值／選項 說明
Vector Vector [0, 0, 0] 要保留方向並轉為單位長度的 Vector。

Output

名稱 型別 預設值／選項 說明
Vector Vector — 長度為 1 的單位向量；輸入接近零向量時無資料。

Vector Length

計算 Vector 從原點到 [x, y, z] 的直線長度。此節點只輸出大小，不保留方向。

Input

名稱 型別 預設值／選項 說明
Vector Vector [0, 0, 0] 要量測長度的 Vector。

Output

名稱 型別 預設值／選項 說明
Length Number — Vector 的三維長度。

Point On Ray

以 Point 為起點，沿 Vector 建立新的 Point。計算方式為 Point 加上 Vector 乘以 Distance，輸出的 Point 可在 Viewport 中 Preview 或 Bake。

Input

名稱 型別 預設值／選項 說明
Point Point (0, 0, 0) 射線的起點。
Vector Vector [0, 0, 0] 從 Point 出發的方向與倍率。
Distance Number 1 套用至 Vector 的倍率；使用單位向量時代表實際位移長度。

Output

名稱 型別 預設值／選項 說明
Point Point — 由起點與 Vector 位移建立的 Point。

Angles

Vector Angle

計算 A 與 B 之間不帶方向的最小夾角，結果介於 0° 與 180°。此節點適合量測兩個方向是否平行、垂直或相反。

Input

名稱 型別 預設值／選項 說明
A Vector [0, 0, 0] 夾角的起始方向。
B Vector [0, 0, 0] 要與 A 比較的方向。

Output

名稱 型別 預設值／選項 說明
Angle Number — A 與 B 之間 0–180° 的最小夾角。

Signed Vector Angle

依 Reference 判斷 A 旋轉至 B 的方向，並輸出 0–360° 的角度。Reference 通常使用旋轉平面的法向量，例如 XY 平面可使用 [0, 0, 1]。

Input

名稱 型別 預設值／選項 說明
A Vector [0, 0, 0] 旋轉的起始方向。
B Vector [0, 0, 0] 旋轉的目標方向。
Reference Vector [0, 0, 1] 用於判斷旋轉側向的參考方向。

Output

名稱 型別 預設值／選項 說明
Angle Number — 依 Reference 判斷的 0–360° 旋轉角度。

Distance

Interpolate Vector

依 Fraction 在 A 與 B 之間建立線性 Vector。Fraction 會作為 A 的權重，1 - Fraction 則作為 B 的權重。

Input

名稱 型別 預設值／選項 說明
A Vector [0, 0, 0] Fraction 權重所對應的 Vector。
B Vector [0, 0, 0] 1 - Fraction 權重所對應的 Vector。
Fraction Number 0.5 A 與 B 的線性權重。

Output

名稱 型別 預設值／選項 說明
Vector Vector — 依 Fraction 計算出的線性 Vector。
