Curve

Curve 節點用來建立及處理 Line 與 Polyline。Line 由起點和終點組成；Polyline 依 Point List 的順序連接各點，並可設定為 Closed。相關幾何可在 Viewport 中預覽，也可 Bake 至專案；長度會依目前專案的長度單位顯示。

Create

Line 2Pt

使用 Start 與 End 建立一條 Line。兩點相同時，建立結果的長度為 0。

Input

名稱 型別 預設值／選項 說明
Start Point (0, 0, 0) 指定起點。
End Point (1, 0, 0) 指定終點。

Output

名稱 型別 預設值／選項 說明
Line Line — 連接兩個輸入位置的線段。

Construct Polyline

依 Point List 的順序連接各點。啟用 Closed 後，顯示與分段結果會連接最後一點和第一點；少於兩個點時不會形成線段。

Input

名稱 型別 預設值／選項 說明
Points Point List — 依序排列的 Point List。
Closed Boolean false 啟用後建立封閉結果。

Output

名稱 型別 預設值／選項 說明
Polyline Polyline — 依輸入順序建立的折線。

Get

Deconstruct Line

取得 Line 的起點與終點。

Input

名稱 型別 預設值／選項 說明
Line Line — 要拆解的線段。

Output

名稱 型別 預設值／選項 說明
Start Point — 起點位置。
End Point — 終點位置。

Point On Line

依 Parameter 取得 Line 上的位置。0 對應起點，1 對應終點；小於 0 或大於 1 時會沿線段方向向外延伸。

Input

名稱 型別 預設值／選項 說明
Line Line — 要取得位置的線段。
Parameter Number 0.5 指定線段上的比例位置。

Output

名稱 型別 預設值／選項 說明
Point Point — Parameter 對應的位置。

Deconstruct Polyline

取得 Polyline 的 Points 與分段 Lines。Closed 啟用時會包含首尾連接線；若最後一點已與第一點重合，則不重複建立該線段。

Input

名稱 型別 預設值／選項 說明
Polyline Polyline — 要拆解的折線。

Output

名稱 型別 預設值／選項 說明
Points Point List — 組成折線的有序位置。
Lines Line List — 相鄰位置形成的線段。

Curve Length

量測 Line 或 Polyline 的長度。Polyline 會加總 Point List 中的相鄰線段；Closed Polyline 目前不包含最後一點回到第一點的距離。

Input

名稱 型別 預設值／選項 說明
Curve Curve — 要量測的 Line 或 Polyline。

Output

名稱 型別 預設值／選項 說明
Length Number — 輸入幾何的長度。

Operations

Reverse Curve

反轉 Line 或 Polyline 的方向。Line 會交換起點與終點；Polyline 會反轉 Point List，並保留原本的 Closed 設定。

Input

名稱 型別 預設值／選項 說明
Curve Curve — 要反轉的 Line 或 Polyline。

Output

名稱 型別 預設值／選項 說明
Curve Curve — 與輸入相同型別的反轉結果。
