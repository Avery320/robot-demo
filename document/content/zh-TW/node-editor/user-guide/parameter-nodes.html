Parameter

Parameter 節點用於建立基礎數值與 Boolean，以及檢視、傳遞或控制 Node Editor 中的資料。

Create

Number Slider

建立一個可由 Slider 或精確數值輸入調整的 Number。

Output

名稱 型別 預設值／選項 說明
Value Number — 目前設定的 Number。

Control

名稱 類型 選項 說明
Value Slider 預設 1；範圍 0 至 20；間隔 0.1 設定輸出的 Number，並可調整 Slider 範圍與精度。

Boolean

建立固定的 Boolean，適合控制 Gate 或其他需要 true／false 的 Input。使用 Value Control 切換狀態後，Output 會立即更新。

Output

名稱 型別 預設值／選項 說明
Value Boolean — Value Control 目前設定的 Boolean。

Control

名稱 類型 選項 說明
Value Boolean True/False 設定輸出的 Boolean，預設為 false。

Panel

顯示連接的資料並將原始資料傳遞至 Output。未連線時可輸入多行文字，並將文字作為 Output。

Input

名稱 型別 預設值／選項 說明
Input Value 空白文字 要顯示與傳遞的資料；未連線時使用 Panel 中輸入的文字。

Output

名稱 型別 預設值／選項 說明
Output Value — 連接的原始資料，或未連線時輸入的文字。

Util

Value Gate

使用 Boolean 決定 Value 是否繼續傳遞。Boolean 為 true 時，Output 保留輸入資料；Boolean 為 false 時，Output 為 no-data。

此節點適合依條件啟用部分資料流程。例如將 Compare 的結果連接至 Boolean，即可只在比較成立時輸出 Point、Plane、Number 或其他 Value。

Input

名稱 型別 預設值／選項 說明
Value Value no-data 要依條件傳遞的原始資料。
Boolean Boolean false true 時傳遞 Value，false 時阻止輸出。

Output

名稱 型別 預設值／選項 說明
Value Value — Boolean 為 true 時輸入的原始 Value；否則為 no-data。
