Plane

Plane 用來表示三維空間中的位置與方向，由 Origin（原點）、Direction（X 軸）與 Normal（Z 軸）組成。可用於幾何操作及機器人目標姿態；建立結果可在 Viewport 中預覽，也可 Bake 至專案。

Create

Construct Plane

使用原點、法向量與方向向量建立 Plane。Normal 指定 Z 軸，Direction 指定 X 軸方向。兩個方向向量不能為零或互相平行。

Input

名稱 型別 預設值／選項 說明
Origin Point (0, 0, 0) 指定原點位置。
Normal Vector [0, 0, 1] 指定 Z 軸方向。
Direction Vector [1, 0, 0] 指定 X 軸方向。

Output

名稱 型別 預設值／選項 說明
Plane Plane — 可連接至其他需要 Plane 的節點。

Plane 3Pt

使用三個點指定原點、X 軸方向與平面朝向。輸入點重合或三點共線時無法建立 Plane。

Input

名稱 型別 預設值／選項 說明
Point 1 Point (0, 0, 0) 指定原點。
Point 2 Point (0, 0, 0) 與 Point 1 共同指定 X 軸方向。
Point 3 Point (0, 0, 0) 指定平面朝向。

Output

名稱 型別 預設值／選項 說明
Plane Plane — 由三個點建立的結果。

Edit

Flip Plane

調整 Plane 的軸向。可分別反轉 X、Y 軸，或交換兩個軸的方向。

Input

名稱 型別 預設值／選項 說明
Plane Plane — 要調整的資料。
Reverse X Boolean false 啟用後反轉 X 軸。
Reverse Y Boolean false 啟用後反轉 Y 軸。
Swap Axes Boolean false 啟用後交換 X、Y 軸。

Output

名稱 型別 預設值／選項 說明
Plane Plane — 軸向調整後的結果。

Get

Deconstruct Plane

取得 Plane 的原點、法向量與方向向量，供後續節點分別使用。

Input

名稱 型別 預設值／選項 說明
Plane Plane — 要拆解的資料。

Output

名稱 型別 預設值／選項 說明
Origin Point — 原點位置。
Normal Vector — Z 軸方向。
Direction Vector — X 軸方向。
