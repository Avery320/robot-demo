RoboSim OLP Instruction Parameters

本文說明 RoboSim OLP Program 目前支援的五種指令：MoveJ、MoveL、MoveAbsJ、WAIT、DO。這些參數會儲存在 Station Tree node 的 meta.programInstruction，並由 OLP Input Builder 轉換後送入 OLP Engine。

通用規則

  • Target 放在 MoveJ 或 MoveL 底下，表示該運動指令要到達的位置。
  • Target 的 x, y, z, roll, pitch, yaw 是相對於所在 Frame 的 local pose；OLP Engine 會依 Frame hierarchy、Robot Base、Tool/TCP 完成 pose resolution。
  • 角度輸入使用 degree；進入 ik solver 前會轉成 quaternion。
  • 關節運算使用 rad；位置運算使用 m；速度欄位依下列參數單位處理。
  • speed.time = 0 表示由速度限制計算運動時間；大於 0 時表示指定該指令的目標時間。
  • zone.distance = 0 表示精準停點；zone.distance > 0 表示 fly-by / blend / approximation。
  • RoboSim 新建 MoveJ / MoveL / MoveAbsJ 指令時，zone.distance 預設為 20 mm，作為保守的平滑過渡起點；需要精準停點時手動設為 0。
  • Zone 已進入 OLP Engine 與 Program Result trace，但不直接改變 IK 解算、MoveL 切片或 Playback sampling。這與 Robots 原專案一致，Zone 主要供後續 post processor 轉換控制器語法。

MoveJ

MoveJ 使用 joint-space 插值，適合點到點移動。MoveJ 的路徑不保證 TCP 在空間中走直線。

Parameter Default Unit Description
type moveJ - 指令類型。
targetId 由子層 Target 自動解析 - 指令底下 Target node 的 id。
segments 20 count RoboSim 內部 playback sampling 預設值；MoveJ Inspector 不提供手動調整。
speed.translation 100 mm/s TCP 平移速度上限，用於時間估算。
speed.rotation 3.14159 rad/s TCP 旋轉速度上限，用於時間估算。
speed.translationExternal 5000 mm/s 外部直線軸速度上限，預留給外部軸。
speed.rotationExternal 18.84956 rad/s 外部旋轉軸速度上限，預留給外部軸。
speed.translationAccel 1000 mm/s² TCP 平移加速度，預留給加速度模型。
speed.axisAccel 3.14159 rad/s² 關節軸加速度，預留給加速度模型。
speed.time 0 s 指定運動時間；0 表示自動計算。
zone.distance 10 mm 通用 Zone 距離；0 為 stop point，大於 0 為 fly-by。

MoveL

MoveL 使用 Cartesian TCP 線性插值，適合要求 TCP 在空間中接近直線的移動。「Cartesian target -> TCP 直線切片 -> 每一片解 IK」。切片數量邏輯是：

  1. 如果 segments > 0，優先使用 segments。
  2. 否則用 distance / stepSize 自動計算。
  3. 如果都沒有，就用預設 DefaultMoveLSegments = 20。
Parameter Default Unit Description
type moveL - 指令類型。
targetId 由子層 Target 自動解析 - 指令底下 Target node 的 id。
segments 0 count 固定取樣段數；0 表示依 stepSize 自動計算。
stepSize 0.01 m Cartesian 路徑取樣距離，預設為 10 mm。
speed.translation 100 mm/s TCP 平移速度上限，用於時間估算。
speed.rotation 3.14159 rad/s TCP 旋轉速度上限，用於時間估算。
speed.translationExternal 5000 mm/s 外部直線軸速度上限，預留給外部軸。
speed.rotationExternal 18.84956 rad/s 外部旋轉軸速度上限，預留給外部軸。
speed.translationAccel 1000 mm/s² TCP 平移加速度，預留給加速度模型。
speed.axisAccel 3.14159 rad/s² 關節軸加速度，預留給加速度模型。
speed.time 0 s 指定運動時間；0 表示自動計算。
zone.distance 10 mm 通用 Zone 距離；0 為 stop point，大於 0 為 fly-by。

speed.rotationExternal 18.84956 rad/s 外部旋轉軸速度上限，預留給外部軸。

speed.axisAccel 3.14159 rad/s² 關節軸加速度，預留給加速度模型。

WAIT

WAIT 會在 Program Result 中產生事件，並把 playback 時間往後推移。

Parameter Default Unit Description
type wait - 指令類型。
seconds 1 s 等待時間。

DO

DO 表示 Digital Output 狀態切換。現階段會在 Program Result 中產生事件，供後續 controller exporter 或 playback UI 使用。

Parameter Default Unit Description
type digitalOutput - 指令類型。
channel 1 index 數位輸出通道。
value true boolean 輸出狀態。

Program Result 時間欄位

每個 trajectory point 會保留下列時間相關欄位，供 playback 與後續 exporter 使用：

Field Description
time 從 Program 開始累積的時間，單位為秒。
deltaTime 當前 motion instruction 的總運動時間。
minTime 依關節速度限制推得的最小時間。
speedType 主要限制來源，目前可能為 axis、tcp、rotation。
leadingJoint 造成 axis 時間限制的關節索引；沒有主導關節時為 -1。
zone 該 trajectory point 所屬 motion instruction 的 Zone trace，包含 distanceMm、rotationRad、rotationExternalRad、isFlyBy。

Zone 與 Robots 對齊

  • distance 是 TCP 線性容差，單位 mm。
  • rotation 是 tool reorientation 容差，單位 rad；若未指定，依 distance / 10 degrees 推導。
  • rotationExternal 是外部旋轉軸容差，單位 rad；若未指定，沿用 rotation。
  • isFlyBy 由 distanceMm > 0.001 判斷。
  • engine 的 missing-zone fallback 仍是 0 mm，避免外部或舊 JSON 未明確提供 Zone 時被自動改成 fly-by。RoboSim 前端新建指令才使用 10 mm 作為產品預設。

品牌控制器語法不寫入通用資料模型：

  • KUKA C_PTP / C_DIS / C_VEL 是 KUKA exporter 的輸出語法。
  • ABB zonedata / fine 是 ABB exporter 的輸出語法。
  • UR r= 是 UR exporter 的輸出語法。

因此 Inspector 目前只顯示 Zone Distance。rotation 與 rotationExternal 自動推導，等 exporter 階段需要進階控制時再開放 UI。
