RoboSim 專案指南

RoboSim 工作區由 Ribbon、Station Tree、Viewport、Tool Panel 與 Runtime Log 組成。本文件說明各區域的職責與共同操作；各系統的完整操作另見對應指南。

專案架構

Station Tree、Viewport 與 Inspector 操作同一份專案資料。Inspector 的修改會透過專案操作系統更新對應物件，不建立另一份設定。

專案資料

專案保存 Station Tree、幾何與 Robot 資產、Node Graph、OLP 計算結果、顯示單位、顯示設定、ROS Bridge 偏好與工作區配置。

即時執行狀態

ROS 即時訊息、相機互動狀態、暫時顯示與 Ghost 執行狀態不作為專案資料保存。ROS Transport、URL 與儲存時的連線狀態會保存；重新開啟專案時，系統會依保存狀態嘗試重新連線。

介面設定

工作區架構

Station Tree

管理專案物件、階層、選取、顯示與鎖定狀態。

Viewport

顯示並操作 Robot、幾何、ROS 資料與 OLP 結果。

Inspector

Inspector 會依目前選取的物件顯示可查看或可修改的內容。

Runtime Log

Runtime Log 依來源與狀態顯示操作結果。建立連線、匯入幾何、載入 Robot、專案存取或運算失敗時，應先查看此區域。

工作區顯示與快捷鍵

快捷鍵 功能 說明
Command/Ctrl + B Station Tree 顯示或收合左側 Station Tree。
Command/Ctrl + Option/Alt + B Tool Panel 顯示或收合右側 Tool Panel。
Command/Ctrl + J Runtime Log 顯示或收合下方 Runtime Log。

面板可使用分隔線調整尺寸。顯示狀態與尺寸會隨目前專案保存。
