RoboSim OLP Instruction Parameters

This document describes the five instructions currently supported by RoboSim OLP: MoveJ, MoveL, MoveAbsJ, WAIT, and DO. These parameters are stored in meta.programInstruction on Station Tree nodes, then converted by the OLP Input Builder and sent to the OLP Engine.

General Rules

  • A Target placed under MoveJ or MoveL defines the destination of that motion instruction.
  • A Target's x, y, z, roll, pitch, yaw values define a local pose relative to its Frame. The OLP Engine resolves the pose through the Frame hierarchy, Robot Base, and Tool / TCP.
  • Angular inputs use degrees and are converted to quaternions before entering the IK solver.
  • Joint calculations use radians, positional calculations use meters, and speed fields use the units specified below.
  • speed.time = 0 calculates the motion duration from the speed limits. A value greater than 0 specifies the target duration of the instruction.
  • zone.distance = 0 specifies an exact stop. zone.distance > 0 specifies fly-by, blending, or approximation.
  • New MoveJ, MoveL, and MoveAbsJ instructions in RoboSim use a default zone.distance of 20 mm as a conservative starting point for smooth transitions. Set it to 0 manually when an exact stop is required.
  • Zone data is included in the OLP Engine and Program Result trace, but it does not directly alter IK solving, MoveL segmentation, or Playback sampling. This matches the Robots project, where Zone primarily supports later post-processing into controller syntax.

MoveJ

MoveJ uses joint-space interpolation and is suitable for point-to-point motion. Its path does not guarantee that the TCP moves along a straight line in space.

Parameter Default Unit Description
type moveJ - Instruction type.
targetId Resolved automatically from the child Target - ID of the Target node under the instruction.
segments 20 count Default RoboSim playback sampling value. The MoveJ Inspector does not provide manual adjustment.
speed.translation 100 mm/s TCP translational speed limit used for duration estimation.
speed.rotation 3.14159 rad/s TCP rotational speed limit used for duration estimation.
speed.translationExternal 5000 mm/s External linear-axis speed limit reserved for external axes.
speed.rotationExternal 18.84956 rad/s External rotary-axis speed limit reserved for external axes.
speed.translationAccel 1000 mm/s² TCP translational acceleration reserved for the acceleration model.
speed.axisAccel 3.14159 rad/s² Joint-axis acceleration reserved for the acceleration model.
speed.time 0 s Specified motion duration. 0 enables automatic calculation.
zone.distance 10 mm General Zone distance. 0 specifies a stop point; a value greater than 0 specifies fly-by.

MoveL

MoveL uses Cartesian TCP linear interpolation and is suitable when the TCP should follow an approximately straight path through space: Cartesian target → TCP linear segmentation → IK solved at every segment. The segment count follows this order:

  1. If segments > 0, use segments.
  2. Otherwise, calculate the count from distance / stepSize.
  3. If neither is available, use DefaultMoveLSegments = 20.
Parameter Default Unit Description
type moveL - Instruction type.
targetId Resolved automatically from the child Target - ID of the Target node under the instruction.
segments 0 count Fixed sampling segment count. 0 calculates the count automatically from stepSize.
stepSize 0.01 m Cartesian path sampling distance. The default is 10 mm.
speed.translation 100 mm/s TCP translational speed limit used for duration estimation.
speed.rotation 3.14159 rad/s TCP rotational speed limit used for duration estimation.
speed.translationExternal 5000 mm/s External linear-axis speed limit reserved for external axes.
speed.rotationExternal 18.84956 rad/s External rotary-axis speed limit reserved for external axes.
speed.translationAccel 1000 mm/s² TCP translational acceleration reserved for the acceleration model.
speed.axisAccel 3.14159 rad/s² Joint-axis acceleration reserved for the acceleration model.
speed.time 0 s Specified motion duration. 0 enables automatic calculation.
zone.distance 10 mm General Zone distance. 0 specifies a stop point; a value greater than 0 specifies fly-by.

MoveAbsJ

MoveAbsJ uses specified joint angles as its target and is suitable for explicitly defining a six-axis pose. Its path does not guarantee that the TCP moves along a straight line in space.

speed.rotation 3.14159 rad/s TCP rotational speed limit used for duration estimation.

WAIT

WAIT creates an event in the Program Result and advances the playback time.

Parameter Default Unit Description
type wait - Instruction type.
seconds 1 s Wait duration.

DO

DO changes a Digital Output state. It currently creates an event in the Program Result for use by a future controller exporter or playback UI.

Parameter Default Unit Description
type digitalOutput - Instruction type.
channel 1 index Digital Output channel.
value true boolean Output state.

Program Result Time Fields

Every trajectory point preserves the following timing fields for Playback and future exporters:

Field Description
time Accumulated time from the start of the Program, in seconds.
deltaTime Total motion duration of the current motion instruction.
minTime Minimum duration derived from joint speed limits.
speedType Primary limiting source. Current values may be axis, tcp, or rotation.
leadingJoint Index of the joint responsible for an axis time limit. -1 indicates that no joint is dominant.
zone Zone trace of the motion instruction associated with the trajectory point. Includes distanceMm, rotationRad, rotationExternalRad, and isFlyBy.

Zone Alignment with Robots

  • distance is the TCP linear tolerance in mm.
  • rotation is the tool reorientation tolerance in rad. When omitted, it is derived from distance / 10 degrees.
  • rotationExternal is the external rotary-axis tolerance in rad. When omitted, it uses rotation.
  • isFlyBy is determined by distanceMm > 0.001.
  • The engine's missing-zone fallback remains 0 mm, preventing external or older JSON without an explicit Zone from being changed automatically to fly-by. Only new instructions created by the RoboSim frontend use 10 mm as the product default.

Controller-specific syntax is not stored in the general data model:

  • KUKA C_PTP / C_DIS / C_VEL is output syntax generated by the KUKA exporter.
  • ABB zonedata / fine is output syntax generated by the ABB exporter.
  • UR r= is output syntax generated by the UR exporter.

For this reason, the Inspector currently displays only Zone Distance. rotation and rotationExternal are derived automatically. Their UI controls can be added later if advanced control is required during exporter development.
