Plane

A Plane represents a position and orientation in three-dimensional space using an Origin, a Direction for its X axis, and a Normal for its Z axis. Planes can define geometry operations and robot target poses. Results can be previewed in the Viewport or baked into the project.

Create

Construct Plane

Creates a Plane from an Origin, Normal, and Direction. Normal specifies the Z axis, while Direction specifies the X-axis direction. Neither direction can be zero, and they cannot be parallel.

Input

Name Type Default / Options Description
Origin Point (0, 0, 0) Origin position.
Normal Vector [0, 0, 1] Direction of the Z axis.
Direction Vector [1, 0, 0] Direction of the X axis.

Output

Name Type Default / Options Description
Plane Plane — Result that can be connected to another Node requiring a Plane.

Plane 3Pt

Uses three Points to define an Origin, X-axis direction, and orientation. A Plane cannot be created if any input Points coincide or all three Points are collinear.

Input

Name Type Default / Options Description
Point 1 Point (0, 0, 0) Defines the Origin.
Point 2 Point (0, 0, 0) Defines the X-axis direction together with Point 1.
Point 3 Point (0, 0, 0) Defines the orientation.

Output

Name Type Default / Options Description
Plane Plane — Result created from the three Points.

Edit

Flip Plane

Adjusts the axis directions of a Plane. The X and Y axes can be reversed independently, or the two axes can be swapped.

Input

Name Type Default / Options Description
Plane Plane — Data to adjust.
Reverse X Boolean false Reverses the X axis when enabled.
Reverse Y Boolean false Reverses the Y axis when enabled.
Swap Axes Boolean false Swaps the X and Y axes when enabled.

Output

Name Type Default / Options Description
Plane Plane — Result after the axes have been adjusted.

Get

Deconstruct Plane

Returns the Origin, Normal, and Direction separately for use by downstream Nodes.

Input

Name Type Default / Options Description
Plane Plane — Data to deconstruct.

Output

Name Type Default / Options Description
Origin Point — Origin position.
Normal Vector — Direction of the Z axis.
Direction Vector — Direction of the X axis.
