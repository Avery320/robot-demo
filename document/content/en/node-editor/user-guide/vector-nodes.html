Vector

Vector Nodes create and process three-dimensional directional data. A Vector consists of X, Y, and Z components and can represent a direction, scale, or displacement, but not a fixed position in space. Use a Point when a position is required.

Each Input can accept an Item, List, or Data Tree. When a List or Data Tree is connected, the system preserves the existing Branch structure and processes each item. To use a Vector as a direction with a fixed magnitude, first use Normalize to convert it to a unit vector of length 1.

Create

Vector XYZ

Creates a Vector from X, Y, and Z components. Values can be entered directly in the three Inputs or supplied by other Math Nodes to create a variable direction.

Input

Name Type Default / Options Description
X Number 0 X component of the Vector.
Y Number 0 Y component of the Vector.
Z Number 0 Z component of the Vector.

Output

Name Type Default / Options Description
Vector Vector — Three-dimensional Vector composed of X, Y, and Z.

Add Vectors

Input

Name Type Default / Options Description
A Vector [0, 0, 0] First Vector.
B Vector [0, 0, 0] Vector to add to A.

Output

Name Type Default / Options Description
Vector Vector — Vector produced by adding A and B component by component.

Base

Cross Product

Calculates the cross product of A and B, producing a Vector perpendicular to both input directions. The output follows the right-hand rule, so swapping A and B reverses its direction.

Input

Name Type Default / Options Description
A Vector [0, 0, 0] First direction of the cross product.
B Vector [0, 0, 0] Second direction of the cross product.

Output

Name Type Default / Options Description
Vector Vector — Perpendicular Vector calculated using the right-hand rule.

Dot Product

Calculates the dot product of A and B and outputs a Number. The result indicates the directional relationship between the Vectors: a positive value means they point in similar directions, a negative value means they point in opposing directions, and 0 means they are perpendicular.

Vector lengths affect the result. Normalize A and B first when only their directions should be compared.

Input

Name Type Default / Options Description
A Vector [0, 0, 0] First Vector of the dot product.
B Vector [0, 0, 0] Second Vector of the dot product.

Output

Name Type Default / Options Description
Number Number — Sum of the products of the corresponding components of A and B.

Subtract Vectors

Subtracts B from A component by component. Use it to find the difference between two directions or to derive a directional difference from positional data.

Input

Name Type Default / Options Description
A Vector [0, 0, 0] Vector from which B is subtracted.
B Vector [0, 0, 0] Vector subtracted from A.

Output

Name Type Default / Options Description
Vector Vector — Vector produced by subtracting B from A.

Multiply Vector

Multiplies every component of a Vector by a Scalar. Use it to preserve the original direction while changing the length, or to scale a displacement proportionally.

A Scalar greater than 1 increases the Vector length, a value between 0 and 1 shortens it, and 0 produces a zero vector. A negative value also reverses the direction.

Input

Name Type Default / Options Description
Vector Vector [0, 0, 0] Vector to scale.
Scalar Number 1 Scale applied to every component.

Output

Name Type Default / Options Description
Vector Vector — Vector after every component has been multiplied by Scalar.

Negate Vector

Reverses a Vector while preserving its original length by changing the sign of every component.

Input

Name Type Default / Options Description
Vector Vector [0, 0, 0] Vector whose direction will be reversed.

Output

Name Type Default / Options Description
Vector Vector — Vector with reversed direction and unchanged length.

Normalize

Converts a Vector into a unit vector of length 1 while preserving its direction. Use it when only the direction is needed and the original length should not affect subsequent operations.

Input

Name Type Default / Options Description
Vector Vector [0, 0, 0] Vector whose direction will be preserved and length normalized.

Output

Name Type Default / Options Description
Vector Vector — Unit vector of length 1; a near-zero input produces no-data.

Vector Length

Calculates the straight-line length from the origin to [x, y, z]. This Node outputs only the magnitude and does not preserve direction.

Input

Name Type Default / Options Description
Vector Vector [0, 0, 0] Vector to measure.

Output

Name Type Default / Options Description
Length Number — Three-dimensional length of the Vector.

Point On Ray

Creates a new Point from a starting Point and a Vector. The calculation adds the Vector multiplied by Distance to the Point. The resulting Point can be previewed in the Viewport or baked into the project.

Input

Name Type Default / Options Description
Point Point (0, 0, 0) Starting Point of the ray.
Vector Vector [0, 0, 0] Direction and scale from the Point.
Distance Number 1 Scale applied to the Vector. When the Vector is normalized, this represents the actual displacement length.

Output

Name Type Default / Options Description
Point Point — Point created from the starting position and Vector displacement.

Angles

Vector Angle

Calculates the smallest unsigned angle between A and B, ranging from 0° to 180°. Use it to determine whether two directions are parallel, perpendicular, or opposite.

Input

Name Type Default / Options Description
A Vector [0, 0, 0] Starting direction of the angle.
B Vector [0, 0, 0] Direction to compare with A.

Output

Name Type Default / Options Description
Angle Number — Smallest angle between A and B in the range 0–180°.

Signed Vector Angle

Uses Reference to determine the rotational direction from A to B and outputs an angle from 0–360°. Reference is typically the normal of the rotation plane; for example, use [0, 0, 1] for the XY plane.

Input

Name Type Default / Options Description
A Vector [0, 0, 0] Starting direction of the rotation.
B Vector [0, 0, 0] Target direction of the rotation.
Reference Vector [0, 0, 1] Reference direction used to determine the rotational side.

Output

Name Type Default / Options Description
Angle Number — Rotation angle in the range 0–360°, oriented by Reference.

Interpolate Vector

Creates a linear Vector between A and B using Fraction. Fraction is used as the weight of A, while 1 - Fraction is used as the weight of B.

Input

Name Type Default / Options Description
A Vector [0, 0, 0] Vector weighted by Fraction.
B Vector [0, 0, 0] Vector weighted by 1 - Fraction.
Fraction Number 0.5 Linear weight applied to A and B.

Output

Name Type Default / Options Description
Vector Vector — Linearly weighted Vector calculated from Fraction.
