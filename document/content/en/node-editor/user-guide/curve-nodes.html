Curve

Curve Nodes create and process Lines and Polylines. A Line consists of a start and end Point. A Polyline connects a Point List in order and can be set to Closed. The resulting geometry can be previewed in the Viewport or baked into the project. Lengths are displayed in the current project length unit.

Create

Line 2Pt

Creates a Line from Start and End. If both Points are identical, the resulting length is 0.

Input

Name Type Default / Options Description
Start Point (0, 0, 0) Start Point.
End Point (1, 0, 0) End Point.

Output

Name Type Default / Options Description
Line Line — Line segment connecting the two input positions.

Construct Polyline

Connects Points in the order of the input Point List. When Closed is enabled, the display and segment output connect the last Point to the first. Fewer than two Points do not form a segment.

Input

Name Type Default / Options Description
Points Point List — Ordered Point List.
Closed Boolean false Creates a closed result when enabled.

Output

Name Type Default / Options Description
Polyline Polyline — Polyline created in the input order.

Get

Deconstruct Line

Returns the start and end Points of a Line.

Input

Name Type Default / Options Description
Line Line — Line segment to deconstruct.

Output

Name Type Default / Options Description
Start Point — Start position.
End Point — End position.

Point On Line

Returns a position on a Line at the specified Parameter. 0 corresponds to the start Point and 1 to the end Point. Values below 0 or above 1 extend beyond the segment along its direction.

Input

Name Type Default / Options Description
Line Line — Line segment to evaluate.
Parameter Number 0.5 Proportional position along the Line.

Output

Name Type Default / Options Description
Point Point — Position corresponding to Parameter.

Deconstruct Polyline

Returns the Points and segment Lines of a Polyline. When Closed is enabled, the closing segment is included. If the last Point already coincides with the first, that segment is not created twice.

Input

Name Type Default / Options Description
Polyline Polyline — Polyline to deconstruct.

Output

Name Type Default / Options Description
Points Point List — Ordered positions that define the Polyline.
Lines Line List — Segments formed by adjacent positions.

Curve Length

Measures the length of a Line or Polyline. For a Polyline, the lengths of adjacent segments in the Point List are added together. A Closed Polyline currently does not include the distance from the last Point back to the first.

Input

Name Type Default / Options Description
Curve Curve — Line or Polyline to measure.

Output

Name Type Default / Options Description
Length Number — Length of the input geometry.

Operations

Reverse Curve

Reverses the direction of a Line or Polyline. A Line swaps its start and end Points. A Polyline reverses its Point List while preserving its Closed setting.

Input

Name Type Default / Options Description
Curve Curve — Line or Polyline to reverse.

Output

Name Type Default / Options Description
Curve Curve — Reversed result with the same type as the input.
