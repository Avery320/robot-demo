Parameter

Parameter Nodes create basic numbers and Boolean values, and display, pass, or control data in the Node Editor.

Create

Number Slider

Creates a Number that can be adjusted with a Slider or entered as an exact value.

Output

Name Type Default / Options Description
Value Number — The currently configured Number.

Control

Name Type Options Description
Value Slider Default 1; range 0 to 20; step 0.1 Sets the output Number. The Slider range and precision can also be adjusted.

Boolean

Creates a fixed Boolean for controlling a Gate or another Input that expects true or false. The Output updates immediately when the Value Control is toggled.

Output

Name Type Default / Options Description
Value Boolean — The Boolean currently set by the Value Control.

Control

Name Type Options Description
Value Boolean True / False Sets the output Boolean. The default is false.

Panel

Displays connected data and passes the original data to the Output. When disconnected, it accepts multiline text and outputs that text.

Input

Name Type Default / Options Description
Input Value Empty text Data to display and pass through. When disconnected, the text entered in the Panel is used.

Output

Name Type Default / Options Description
Output Value — The original connected data, or the entered text when disconnected.

Util

Value Gate

Uses a Boolean to determine whether a Value continues through the data flow. When Boolean is true, the Output preserves the input data. When Boolean is false, the Output is no-data.

This Node is useful for enabling part of a data flow conditionally. For example, connect the result of Compare to Boolean to output a Point, Plane, Number, or another Value only when the comparison is true.

Input

Name Type Default / Options Description
Value Value no-data Original data to pass conditionally.
Boolean Boolean false Passes Value when true; blocks the output when false.

Output

Name Type Default / Options Description
Value Value — The original input Value when Boolean is true; otherwise no-data.
