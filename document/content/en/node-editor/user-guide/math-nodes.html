Math

Math Nodes create numerical and comparison workflows. A Number Input can accept a value entered directly in the Node or a Number, List, or Data Tree from another Node. When a List or Data Tree is connected, the system processes each item while preserving the existing Branch structure.

If an input falls outside the definition of an operation—for example, division by 0, taking the square root of a negative number, or producing an infinite value—the Node reports a data error and does not output an invalid Number.

Operations

Two Numbers

Performs basic arithmetic on two values. Connect the primary value to First and the other operand to Second, then choose the calculation from Operation.

The order of First and Second affects Subtract, Divide, Power, and Modulus. For example, when First is 10 and Second is 3, Subtract returns 7 and Modulus returns 1.

Input

Name Type Default / Options Description
First Number 1 Primary operand.
Second Number 1 Second operand.

Output

Name Type Default / Options Description
Result Number — Value calculated using Operation.

Control

Name Type Options Description
Operation Select Add Adds First and Second. Use it to calculate a total or apply an offset. This is the default option.
Subtract Subtracts Second from First. Use it to calculate the difference between two values.
Multiply Multiplies First by Second. Use it to apply a scale or ratio.
Divide Divides First by Second. Use it to calculate a ratio; Second cannot be 0.
Power Raises First to the power of Second.
Modulus Returns the remainder after dividing First by Second. Use it for cyclic indexes or periodic conditions; Second cannot be 0.

Compare

Compares A and B using Operator and outputs the result. Numerical comparisons usually use <, <=, >, or >=. To determine whether two values are equal, prefer === or !==.

A and B accept general Values, but each Operator is suitable for different data. Ordering comparisons are intended for Numbers or Text. Objects such as Geometry Artifacts are not compared by geometric content; strict equality only determines whether both Inputs reference the same object data.

Input

Name Type Default / Options Description
A Value no-data Data on the left side of the comparison.
B Value no-data Data on the right side of the comparison.

Output

Name Type Default / Options Description
Boolean Boolean — Whether A and B satisfy Operator.

Control

Name Type Options Description
Operator Select < Returns true when A is less than B. This is the default option.
<= Returns true when A is less than or equal to B.
> Returns true when A is greater than B.
>= Returns true when A is greater than or equal to B.
=== Returns true when Primitive values have the same type and value. Objects are equal only when they are the same data reference.
!== Returns true when A and B are not strictly equal.
== Allows JavaScript type conversion before comparison. For example, Number 1 and Text 1 are treated as equal.
!= Allows type conversion before comparison and returns true when the converted values differ.

Round To Decimals

Rounds a Number to a specified number of decimal places. Connect the original value to Number and use Decimal Places to set the retained precision.

For example, when Number is 1.32156 and Decimal Places is 3, Result is 1.322. The Output remains a Number and does not preserve trailing zeros that have no numerical significance. Use To Fixed when fixed-width text formatting is required.

Input

Name Type Default / Options Description
Number Number 1.123456 Value to round.
Decimal Places Number 2 Number of decimal places to retain.

Output

Name Type Default / Options Description
Result Number — Rounded value that can continue through numerical operations.

One Number

Performs a mathematical operation that requires one input value. Connect a value to Number, then choose an absolute-value, logarithmic, rounding, trigonometric, or angle-conversion operation.

Sin, Cos, and Tan use radians. Convert degree inputs with Degrees to Radians first. Some operations have restricted input domains; values outside those domains do not produce invalid output.

Input

Name Type Default / Options Description
Number Number 1 Value to which Operation is applied.

Output

Name Type Default / Options Description
Result Number — Value after applying the selected Operation.

Control

Name Type Options Description
Operation Select Absolute Removes the negative sign and returns the absolute value.
Negate Reverses the sign.
Ln Calculates the logarithm with base e. Number must be greater than 0.
Log10 Calculates the logarithm with base 10. Number must be greater than 0.
Ten Pow Raises 10 to the power of Number.
Round Rounds to the nearest integer.
Floor Rounds toward negative infinity.
Ceil Rounds toward positive infinity.
Square Root Calculates the square root. Number must be greater than or equal to 0.
Sin Calculates the sine of an angle in radians.
Cos Calculates the cosine of an angle in radians.
Tan Calculates the tangent of an angle in radians.
Asin Calculates an angle in radians from a sine value. Number must be between -1 and 1.
Acos Calculates an angle in radians from a cosine value. Number must be between -1 and 1.
Atan Calculates an angle in radians from a tangent value.
Exp Raises the natural constant e to the power of Number.
Radians to Degrees Converts radians to degrees.
Degrees to Radians Converts degrees to radians for use with Sin, Cos, or Tan.

Remap

Maps a value proportionally from one interval to another. Define the source interval with Source Low and Source High, then define the output interval with Target Low and Target High.

For example, when mapping 0–100 to 0–1, a Number of 50 produces 0.5. Number may lie outside the source interval; Result then extends beyond the target interval by the same proportion. Source Low and Source High cannot be equal.

Input

Name Type Default / Options Description
Number Number 0.5 Original value to map.
Source Low Number 0 Start of the source interval.
Source High Number 1 End of the source interval. Cannot equal Source Low.
Target Low Number 1 Start of the target interval.
Target High Number 2 End of the target interval.

Output

Name Type Default / Options Description
Result Number — Proportional value of Number in the target interval.

Ease

Transforms X between 0–1 using an accelerating, decelerating, or elastic curve, then maps the result to Min and Max. Use it for animation progress, parameter transitions, or motion values that should not change linearly.

An X of 0 is the start of the transition, and 1 is the end. Ease In primarily affects how the transition starts, Ease Out affects how it approaches the end, and Ease In Out affects both. Elastic and Back curves can temporarily exceed Min or Max and are suitable for oscillation or overshoot effects.

Input

Name Type Default / Options Description
X Number 0.5; range 0 to 1 Progress along the curve, where 0 is the start and 1 is the end.
Min Number 0 Start of the output range.
Max Number 1 End of the output range.

Output

Name Type Default / Options Description
Result Number — Value calculated from the selected curve and mapped to Min and Max.

Control

Name Type Options Description
Ease Select easeInSine Sine ease-in that starts smoothly and gradually accelerates. This is the default option.
easeOutSine Sine ease-out that decelerates smoothly near the end.
easeInOutSine Sine ease-in-out with smooth transitions at both ends.
easeInQuad Quadratic ease-in with a slow start and continuous acceleration.
easeOutQuad Quadratic ease-out with a fast start and continuous deceleration.
easeInOutQuad Quadratic ease-in-out with gentle, smooth changes at both ends.
easeInCubic Cubic ease-in with more pronounced acceleration than Quad.
easeOutCubic Cubic ease-out with more pronounced deceleration than Quad.
easeInOutCubic Cubic ease-in-out with a faster transition through the middle.
easeInQuart Quartic ease-in with a slower start and stronger late acceleration.
easeOutQuart Quartic ease-out with a faster start and stronger final deceleration.
easeInOutQuart Quartic ease-in-out with most of the change concentrated near the middle.
easeInQuint Quintic ease-in with strong late acceleration.
easeOutQuint Quintic ease-out with strong final deceleration.
easeInOutQuint Quintic ease-in-out with the strongest dwell near both ends.
easeInExpo Exponential ease-in that starts nearly stationary before accelerating rapidly.
easeOutExpo Exponential ease-out that starts rapidly and slows significantly near the end.
easeInOutExpo Exponential ease-in-out that is nearly stationary at both ends.
easeInCirc Circular ease-in that accelerates along a circular curve.
easeOutCirc Circular ease-out that decelerates along a circular curve.
easeInOutCirc Circular ease-in-out with smooth ends and a faster middle transition.
easeInElastic Elastic ease-in that oscillates near the start before accelerating toward the end.
easeOutElastic Elastic ease-out that oscillates around the endpoint.
easeInOutElastic Elastic ease-in-out that oscillates near both the start and end.
easeInBack Back ease-in that first moves in the opposite direction before advancing.
easeOutBack Back ease-out that overshoots the endpoint and returns.
easeInOutBack Back ease-in-out that reverses near the start and overshoots before returning at the end.
easeInBounce Bounce ease-in that rebounds near the start before advancing.
easeOutBounce Bounce ease-out that creates a landing rebound near the end.
easeInOutBounce Bounce ease-in-out that rebounds near both the start and end.

Clamp

Restricts Number to the range between Min and Max. Values below Min return Min, values above Max return Max, and values within the range remain unchanged.

Use it to constrain percentages, speeds, dimensions, or other parameters to fixed limits. For example, with Min set to 0 and Max set to 10, an input of 15 returns 10. Min should be less than or equal to Max.

Input

Name Type Default / Options Description
Number Number 0.5 Value to inspect and constrain.
Min Number 0 Smallest permitted output.
Max Number 1 Largest permitted output.

Output

Name Type Default / Options Description
Result Number — Value constrained between Min and Max.

Lerp

Calculates a linear position from Start to End using T. When T is 0, the result is Start; when T is 1, the result is End; and when T is 0.5, the result is halfway between them.

T is not automatically restricted to 0–1. Values below 0 or above 1 extend Result beyond the Start and End range along the same direction.

Input

Name Type Default / Options Description
Start Number 0 Starting value of the linear transition.
End Number 1 Ending value of the linear transition.
T Number 0.5 Proportional position from Start to End.

Output

Name Type Default / Options Description
Result Number — Linearly interpolated or extrapolated value calculated from T.

Sign

Returns the direction of Number without preserving its magnitude. Negative values return -1, zero returns 0, and positive values return 1.

Use this result to determine a movement direction, create a positive or negative scale, or control a data flow with Compare and Value Gate.

Input

Name Type Default / Options Description
Number Number 0 Value whose sign will be evaluated.

Output

Name Type Default / Options Description
Result Number — Sign of Number: -1, 0, or 1.

To Fixed

Converts a Number to Text with a fixed number of decimal places. Unlike Round To Decimals, this Node preserves trailing zeros and is suitable for display, labels, or fixed-format output.

For example, when Number is 5 and Decimal Places is 3, Text is 5.000. The Output type is Text and cannot be used directly in subsequent numerical operations.

Input

Name Type Default / Options Description
Number Number 1 Value to convert to fixed-format text.
Decimal Places Number 2 Fixed number of decimal places displayed in the text. Use an integer from 0 to 100.

Output

Name Type Default / Options Description
Text Text — Text preserving the specified decimal places and trailing zeros.

Generate

Random Numbers

Creates a reproducible sequence of pseudo-random values with a specified range and length. Set the range with Low and High, the sequence length with Count, and its contents with Seed.

The same Low, High, Count, and Seed always produce the same result, so Canvas reevaluation does not change the values arbitrarily. Change Seed to obtain another sequence. Two Random Numbers Nodes with identical settings also produce identical sequences.

Input

Name Type Default / Options Description
Low Number 0 Start of the range for each random value.
High Number 1 End of the range for each random value.
Count Number 10 Number of values to generate. Must be a non-negative integer.
Seed Number 1 Integer that determines the sequence. Change Seed to obtain another result.

Output

Name Type Default / Options Description
Numbers Number List — Numerical sequence generated from the range, Count, and Seed.

Pi

Multiplies the input Number by π. Number acts as a multiplier: an input of 1 returns π, while 2 returns 2π.

Use this Node to construct angles expressed in terms of π or for circular calculations. For example, input 1 for half a revolution in radians, or 2 for a full revolution.

Input

Name Type Default / Options Description
Number Number 1 Multiplier applied to π.

Output

Name Type Default / Options Description
Result Number — Product of Number and π.
