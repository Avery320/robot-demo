OLP

OLP Nodes turn Planes or Joint Targets into robot instructions that RoboSim can calculate, preview, or play back. A Plane defines the target position and orientation, a Joint Target defines six joint values, and Program Settings defines the start and end states used for calculation.

Create

Joint

Creates a Joint Target from six joint values. This Node creates joint data only; it does not define Speed, Zone, or a motion type.

Input

Name Type Default / Options Description
Joint 1 Number 0 Joint value for axis 1, in degrees.
Joint 2 Number 0 Joint value for axis 2, in degrees.
Joint 3 Number 0 Joint value for axis 3, in degrees.
Joint 4 Number 0 Joint value for axis 4, in degrees.
Joint 5 Number 0 Joint value for axis 5, in degrees.
Joint 6 Number 0 Joint value for axis 6, in degrees.

Output

Name Type Default / Options Description
Joint Target OLP Joint Target — Target data containing all six joint values.

Start / End Settings

Defines the start and end states used for OLP calculation.

Input

Name Type Default / Options Description
Start Joint OLP Joint Target — Joint state at the beginning of the program.
End Joint OLP Joint Target — Joint state at the end of the program.

Output

Name Type Default / Options Description
Program Settings OLP Program Settings — Calculation settings containing the Start Joint and End Joint.

MoveJ

Creates a joint-interpolated instruction from a Plane. The robot moves to the target in joint space; the TCP path is not guaranteed to be linear.

Input

Name Type Default / Options Description
Plane Plane — Target position and orientation for the robot.
Speed Number 100 TCP translational speed in mm/s. Must be greater than or equal to 0.
Rotation Speed Number π TCP rotational speed in rad/s. Must be greater than or equal to 0.
Zone Number 50 Path blending distance in mm; 0 specifies an exact stop.

Output

Name Type Default / Options Description
Instruction OLP Instruction — MoveJ instruction.

Control

Name Type Options Description
Tool Frame Select Tool Frames from the Ribbon Specifies which TCP the Plane represents. A new Node uses the currently active Tool Frame by default.
Configuration Select Auto Allows the OLP solver to select the joint configuration automatically.
None Does not specify a Shoulder, Elbow, or Wrist configuration.
Shoulder Specifies the Shoulder configuration.
Elbow Specifies the Elbow configuration.
Wrist Specifies the Wrist configuration.
Shoulder + Elbow Specifies both the Shoulder and Elbow configurations.
Shoulder + Wrist Specifies both the Shoulder and Wrist configurations.
Elbow + Wrist Specifies both the Elbow and Wrist configurations.
Shoulder + Elbow + Wrist Specifies the Shoulder, Elbow, and Wrist configurations.

MoveL

Creates a linearly interpolated instruction from a Plane. OLP samples the Cartesian path and solves the joint state at each sample.

Input

Name Type Default / Options Description
Plane Plane — Target position and orientation for the robot.
Speed Number 100 TCP translational speed in mm/s. Must be greater than or equal to 0.
Rotation Speed Number π TCP rotational speed in rad/s. Must be greater than or equal to 0.
Zone Number 50 Path blending distance in mm; 0 specifies an exact stop.
Segments Number 0 Fixed number of sampling segments. Values greater than 0 use a fixed segment count; 0 calculates the count from Step Size.
Step Size Number 0.01 Sampling interval used when Segments is 0, entered in the current project display unit.

Output

Name Type Default / Options Description
Instruction OLP Instruction — MoveL instruction.

Control

Name Type Options Description
Tool Frame Select Tool Frames from the Ribbon Specifies which TCP the Plane represents. A new Node uses the currently active Tool Frame by default.

Execute

Calculate

Combines one or more OLP Instructions into a program in input order, then calculates the program using the current Station, Robot, and Program Settings. Calculate does not run automatically; click Run to start the calculation.

Input

Name Type Default / Options Description
Instructions OLP Instruction List — Instructions executed in order. They must be supplied in a single List containing at least one Instruction.
Program Settings OLP Program Settings Start / End Joints 1–6 are all 0 Defines the program's start and end joint states. When disconnected, fixed zero values are used.

Output

Name Type Default / Options Description
Result OLP Result — Completed calculation result used by Playback.

Control

Name Type Options Description
Run Action — Calculates the OLP program using the current Instructions and Program Settings.

Robot Preview

Applies a single motion instruction directly to the Viewport Robot for a quick preview of a MoveJ, MoveL, or MoveAbsJ target state. This Node does not perform a complete OLP calculation and does not produce a Result.

  • MoveJ / MoveL: Uses the instruction's Plane and Tool Frame to update the Robot through the Viewport TCP controls and IK solver.
  • MoveAbsJ: Applies the six joint values directly to the Viewport Robot.

Input

Name Type Default / Options Description
Instruction OLP Instruction — One MoveJ, MoveL, or MoveAbsJ instruction.

Control

Name Type Options Description
Run Action — Immediately updates the Viewport Robot and joint display. An error is shown if Program Playback is active or the target cannot be applied.

Playback

Plays an OLP Result produced by Calculate. The Result must still exist in the current execution session. After recalculation, use the new Result.

Input

Name Type Default / Options Description
Result OLP Result — Completed calculation result from Calculate.

Control

Name Type Options Description
Run / Pause Action — Loads the Result and toggles playback or pause.
Speed Select 0.5x, 1x, 2x, 5x, 20x, 50x, 100x, 200x Sets the playback speed. The default is 5x.
Timeline Slider 0 to the total Result duration Adjusts the playback time. Interaction pauses playback and uses an interval of 0.01.
