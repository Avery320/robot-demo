Point

A Point represents a position in three-dimensional space. Point Nodes create, measure, deconstruct, and organize positional data. Coordinates, distances, and tolerances use the current project length unit for input and display.

Create

Point XYZ

Creates a Point from X, Y, and Z coordinates.

Input

Name Type Default / Options Description
X Number 0 Coordinate on the X axis.
Y Number 0 Coordinate on the Y axis.
Z Number 0 Coordinate on the Z axis.

Output

Name Type Default / Options Description
Point Point — The resulting position in three-dimensional space.

Normal From Three Points

Calculates a normal vector from three Points. The input order determines its direction. The calculation fails if any input Points coincide or all three Points are collinear.

Input

Name Type Default / Options Description
Point 1 Point (0, 0, 0) First reference Point.
Point 2 Point (0, 0, 0) Second reference Point.
Point 3 Point (0, 0, 0) Third reference Point.
Reverse Normal Boolean false Reverses the normal vector when enabled.

Output

Name Type Default / Options Description
Normal Vector — Unit vector perpendicular to the plane defined by the three Points.

Measure

Point Distance

Measures the straight-line distance between Start Point and End Point.

Input

Name Type Default / Options Description
Start Point Point (0, 0, 0) Starting position of the measurement.
End Point Point (0, 0, 0) Ending position of the measurement.

Output

Name Type Default / Options Description
Distance Number — Distance between the two Points.

Extract

Deconstruct Point

Returns the X, Y, and Z coordinates of the input position.

Input

Name Type Default / Options Description
Point Point (0, 0, 0) Position to deconstruct.

Output

Name Type Default / Options Description
X Number — Coordinate on the X axis.
Y Number — Coordinate on the Y axis.
Z Number — Coordinate on the Z axis.

Average Point

Calculates the average position of all Points in a Point List. The input List cannot be empty.

Input

Name Type Default / Options Description
Points Point List — Point List whose average position will be calculated.

Output

Name Type Default / Options Description
Point Point — Average of all input positions.

Closest Point

Finds the item in a Point List that is closest to a specified position. If multiple items are equally close, the first item is returned.

Input

Name Type Default / Options Description
Points Point List — Non-empty Point List to search.
Point Point (0, 0, 0) Reference position for the search.

Output

Name Type Default / Options Description
Point Point — Item closest to the reference position.

Closest Point Distance

Measures the distance between a specified position and the closest item in a Point List. The input List cannot be empty.

Input

Name Type Default / Options Description
Points Point List — Non-empty Point List to search.
Point Point (0, 0, 0) Reference position for the search.

Output

Name Type Default / Options Description
Distance Number — Distance between the reference position and the closest item.

Closest Point Index

Returns the Index of the closest item in a Point List. Indexes are zero-based. If multiple items are equally close, the first Index is returned.

Input

Name Type Default / Options Description
Points Point List — Non-empty Point List to search.
Point Point (0, 0, 0) Reference position for the search.

Output

Name Type Default / Options Description
Index Number — Position of the closest item in the input List.

Clean

Remove Consecutive Point Duplicates

Removes adjacent duplicate Points within a specified Tolerance. Duplicate items that are not adjacent are preserved.

Input

Name Type Default / Options Description
Points Point List — Point List to clean.
Tolerance Number 0.0000001 Tolerance used to identify duplicate positions. Must be greater than or equal to 0.
Check First And Last Boolean false Also compares the first and last items when enabled. If they are duplicates, the last item is removed.

Output

Name Type Default / Options Description
Points Point List — List after adjacent duplicate items have been removed.
