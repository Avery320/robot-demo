List

List Nodes create, select, and modify ordered data. The Tree category operates on complete Data Trees. Other categories process the List within each Branch independently. Indexes are zero-based.

Tree

Merge

Merges Data Trees in top-to-bottom Input order. Items with the same Path are appended in sequence, while different Paths preserve their original hierarchy.

Input

Name Type Default / Options Description
Tree 0…N Data Tree At least two Inputs Automatically adds the next Input after a connection. Redundant Inputs are removed when connections are disconnected.

Output

Name Type Default / Options Description
Tree Data Tree — Merged Data Tree.

Flatten

Collects all Items in Branch Path order and places them in a single root Branch {0}.

Input

Name Type Default / Options Description
Tree Data Tree — Data Tree to flatten.

Output

Name Type Default / Options Description
Tree Data Tree — Data Tree with all Items in {0}.

Graft

Places every Item in its own child Branch. Each new Path appends the Item Index to the original Path. Empty Branches are preserved.

Input

Name Type Default / Options Description
Tree Data Tree — Data Tree to which another hierarchy level will be added.

Output

Name Type Default / Options Description
Tree Data Tree — Data Tree with each Item in its own child Branch.

Branch

Returns the Items from a Branch identified by Path. If the Path does not exist, the Output is an empty List.

Input

Name Type Default / Options Description
Tree Data Tree — Data Tree to query.
Path Text {0} Branch Path, such as {0;1}. Every level must be a non-negative integer.

Output

Name Type Default / Options Description
List List — Items in the specified Branch.

Input

Name Type Default / Options Description

Index Number 0 Item position. Must be a non-negative integer.

Output

Name Type Default / Options Description
Item Value — Original data at the specified position.

Sub List

Returns the Items between Start and End. The result includes Start but excludes End.

Input

Name Type Default / Options Description
List List — List from which Items will be extracted.
Start Number 0 Starting Index. Must be a non-negative integer.
End Number 1 Ending Index. Must be a non-negative integer and is excluded from the result.

Output

Name Type Default / Options Description
List List — Items within the specified range.

By Pattern

Filters Items using a Boolean Pattern. When Pattern is shorter than List, it repeats cyclically. An empty Pattern or a Pattern containing non-Boolean data produces an error.

Input

Name Type Default / Options Description
List List — List to filter.
Pattern Boolean List — true keeps the corresponding Item; false excludes it.

Output

Name Type Default / Options Description
List List — List filtered by Pattern.

Add

Insert Items

Inserts Items at specified Indexes. An Index equal to the List length appends data to the end. An Index outside the valid range does not insert data.

Input

Name Type Default / Options Description
List List — Original List.
Items List — Items to insert.
Indexes Number List — Insertion positions. Values must be non-negative integers.

Output

Name Type Default / Options Description
List List — List after insertion.

Pairing rules:

  • One Item and multiple Indexes: inserts the same Item at every position.
  • Multiple Items and one Index: inserts all Items in order starting at that position.
  • Equal numbers of Items and Indexes: inserts them one-to-one in order. Indexes must be sorted in ascending order.
  • Other count combinations produce an error.

Remove

Removes Items at specified Indexes. An Index outside the List range is ignored.

Input

Name Type Default / Options Description

Output

Name Type Default / Options Description
List List — List after the specified Items have been removed.

Remove Duplicates

Removes duplicate Items using strict equality and preserves the first occurrence. Objects are considered duplicates only when they share the same reference.

Input

Name Type Default / Options Description
List List — List from which duplicate data will be removed.

Output

Name Type Default / Options Description
List List — List preserving the first occurrence of each Item.

Sorting

Sorts a Number List by numerical value. A List containing a non-finite Number produces an error.

Input

Name Type Default / Options Description
List Number List — Finite Number List to sort.
Ascending Boolean true true sorts in ascending order; false sorts in descending order.

Output

Name Type Default / Options Description
List Number List — Sorted Number List.

Input

Output

Name Type Default / Options Description
List Text List — Sorted Text List.
