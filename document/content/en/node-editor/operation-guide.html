Node Editor User Guide

The Node Editor is used to build data, geometry, and robot-control workflows. Nodes pass data through connections. Nodes with geometry outputs can preview their results directly in the Viewport or bake them into project geometry.

Available Node Groups

Nodes are organized by Group in the palette on the left side of the Canvas.

Group Description
Parameter Creates numbers and Boolean values, and displays data.
Point Creates, measures, and organizes 3D positions.
Plane Creates, edits, and deconstructs Planes.
Curve Creates and processes Lines and Polylines.
Mesh Retrieves Viewport Meshes and performs Mesh operations; documentation is not yet available.
OLP Creates robot instructions, previews poses, calculates programs, and controls playback.
Vector Creates and operates on 3D directions.
Math Performs numerical operations and generates values.
List Operates on Lists and Data Trees.

Basic Node Operations

Create and Search

Function Operation Description
Search and create Double-click an empty area of the Canvas, or press Space while the Node Editor has focus. Enter a keyword to search by the complete Group / Sub Group / Node path.
Locate an existing Node Hold Command + Option and left-click an existing Node. Opens the Node's Group and locates the corresponding item.

Edit Nodes

Operation Description
Ctrl/Command + C Copies the selected Nodes.
Ctrl/Command + X Cuts the selected Nodes.
Ctrl/Command + V Pastes Nodes.
Delete / Backspace Deletes the selected Nodes, connections, or Group.
Ctrl/Command + Z Undoes the previous operation.
Ctrl/Command + Shift + Z Redoes the previous operation.
Ctrl/Command + Y Redoes the previous operation.

Create Groups

A Group treats related Nodes as a single unit for editing. It does not participate in data evaluation.

Operation Description
Ctrl/Command + G Creates a Group from the selected Nodes.
Ctrl/Command + Shift + G Removes the selected Nodes from their Group, or ungroups the selected Group.

Node Connections

Operation Description
Create a connection Drag or click from an Output to an Input. A connection can also be started from an Input and completed at an Output.<br>By default, each Input keeps only its newest connection. Creating a new connection automatically removes the previous one.
Create multiple connections Hold Shift while creating the second and subsequent connections to pass multiple sources into the same Input. Data order follows connection order.<br>When order affects the result, create the connections one at a time in the required sequence.
Remove a connection Hold Ctrl or Command and reconnect the same Output and Input to remove that connection.<br>You can also select a connection and press Delete or Backspace.
Add Inputs automatically Merge adds the next Input after a successful connection. Removing the final connection also removes redundant empty Inputs while keeping one Input available for the next connection.

Node Status and Hints

Status Display Description
Normal Standard project Node style Input data is valid and the Node has completed evaluation successfully.
Warning Orange Some data could not be processed, but valid output is still available; a connection may also form a cyclic dependency.
Error Red No input data could be processed, no valid output could be produced, or an action failed.

Node Hints

Hover over a Node title or an Input / Output to view:

Content Description
Node name Shows the Node name and its primary purpose.
Input Describes the expected input data.
Output Describes the generated output data.

Node Alignment and Distribution

Function Operation Description
Input / Output alignment Drag a Node until an Input or Output approaches the corresponding Output or Input on another Node. Aligns the ports vertically and displays a horizontal guide. This does not snap the Node to the Canvas grid.
Align multiple Nodes Drag a selection box across an empty area of the Canvas to select two or more Nodes. Alignment controls appear above and to the right of the selection. They provide left, horizontal-center, right, top, vertical-center, and bottom alignment.
Distribute multiple Nodes Select three or more Nodes with a selection box. Distributes the selected Nodes evenly in the horizontal or vertical direction.

Node-Specific Controls

Panel

A Panel displays data and can also provide text input.

  • When disconnected, it accepts editable multiline text and outputs Text.
  • When connected, it displays the Item, List, or Data Tree structure of the input.
  • A Panel formats data for display without changing the original value passed downstream.
  • Panel content can be scrolled when it exceeds the available area.
  • Drag the Panel boundary to adjust its width and height.

Number Slider

  • Drag the Slider to adjust its value.
  • Double-click the displayed value to enter an exact number.
  • Right-click a single Number Slider to set Min, Max, and Value.
  • Drag the Node boundary horizontally to adjust the Slider width.

Action

Nodes with an Action display an operation button, such as Run.

  • The corresponding operation runs only when the button is clicked.
  • The button is temporarily disabled while the operation is running.
  • If the operation fails, the Node enters the Error state and displays an error hint.

Select

Select controls choose Node options such as Tool Frame or Configuration. Options are supplied by the Node definition or the current project state.

Display Operations

Node Display Settings

Right-click a Node to open its operation menu. If multiple Nodes are selected, the setting is applied to all selected Nodes.

Function Description
Preview Shows or hides the Node's geometry preview in the Viewport. This option is available only for Nodes with geometry outputs.
Enable Enables or disables Node evaluation. A disabled Node produces no output.
Bake Creates project geometry from the current result. This option is available only for geometry that can be previewed.

Preview controls temporary display only. Project geometry created by Bake is not affected by the Preview mode.

Viewport Preview

  • Geometry previews are displayed in red by default.
  • When a Node is selected, its geometry preview is displayed in green.
  • Closing the Node Editor window does not clear the Node Graph or its Viewport previews.

Global Preview Modes

The upper-right corner of the Canvas provides three global preview modes:

Function Description
Show all previews Shows geometry from every Node with Preview enabled.
Show selected previews Shows geometry only from the currently selected Nodes.
Hide all previews Hides all Node geometry previews.

If Preview is disabled on an individual Node, that Node remains hidden even when the global mode is Show all previews.

Canvas Operations

Zoom Operations

Function Description
Zoom All Click Zoom All in the upper-right corner of the Canvas to fit all Nodes into the current view.
Zoom Selected Select Nodes or a Group, then click Zoom Selected to fit the valid selection into the current view. Selecting a Group includes all member Nodes in the calculation.
